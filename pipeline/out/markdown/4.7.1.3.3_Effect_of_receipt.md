# 4.7.1.3.3 Effect of receipt

4.7.1.3.3 Effect of receipt
Link Aggregation Sublayer (optional)
The Link Aggregation Sublayer defines sublayer between PCS and DLL, which maps Physical Layer
Port Primitives between a single port on the DLL side to multiple ports on the PCS side. Its
implementation is optional.
