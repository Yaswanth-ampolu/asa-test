# 4.4.2.5.3 Transmitter Jitter Specification

4.4.2.5.3 Transmitter Jitter Specification
The peak-to-peak value of the transmitter jitter relative to an unjittered reference clock shall be less
than 16.66ps (0.1UI) in all the consecutive 50 times measurements.
The test mode for jitter is described in 4.4.1.1.3.
