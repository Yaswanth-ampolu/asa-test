# 5.5.3.11 LSconfirm

5.5.3.11LSconfirm
There is no address for this command. Instead, two parameters are provided.
Byte Bit(s) Name | Description
n+1 7:0 | RestartCycles1G_a[7:0] Number of Phase1G patterns required to restart
n+2 7:0 | RestartCyclesSGx_a[7:0] Number of PhaseSGA/B/C patterns required to
restart
n+3 | Reserved
