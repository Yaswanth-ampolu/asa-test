# 7.5.2.2 Write Command

7.5.2.2 Write Command
The header of the write command contains five additional bytes:
Byte Bit(s) Name | Description
m +3 7:0 | Slave address | The slave address of the I2C write command
HB
m +4 7:0 | Offset address [15:8]
HB
The offset address of the I2C write command
m +5 7:0 | Offset address [7:0]
HB
m +6 7:0 | Length[15:8]
HB
Length (in bytes) of the write data
m +7 7:0 | Length[7:0]
HB
Table 7-18: ASEP I2C–Write command header
The payload of the write command contains as many bytes as indicated in the header.
Byte Bit(s) Name | Description
m +7+n 7:0 | wdata | n-th byte of write data of I2C command
HB
