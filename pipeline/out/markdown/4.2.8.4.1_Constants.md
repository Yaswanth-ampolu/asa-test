# 4.2.8.4.1 Constants

4.2.8.4.1 Constants
ptb_ACQ_window | Type: Integer
Value: 16
Acquisition window, number of Follow messages to evaluate before
locked status
ptb_LOCK_thresh | Type: Integer
Value: 14
Number of minimum follow messages to be in sync within an acquisition
window to be in lock status
ptb_LOCK_tol | Type: Integer
Value: 2
Maximum deviation (in PTB tics) of local PTB clock versus follow-updated
PTBclk to be in sync
