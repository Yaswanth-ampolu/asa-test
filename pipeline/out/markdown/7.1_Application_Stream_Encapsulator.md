# 7.1 Application Stream Encapsulator

The Application Stream Encapsulator (ASE) acts as a transmitter on a DLP_TX whereas the Application
Stream Decapsulator (ASD) acts as a receiver on a DLP_RX. Each ASE and ASD on a specific Data Link
Layer Port supports only a single ASEP (see 3.5.1.2).
INFORMATIVE: A possible communication between an ASE and ASD in the same node for the
construction of an ASEP transceiver for bidirectional protocols is up to the implementer.
Application Stream Encapsulator
The ASE converts application stream data units into an ASEP format, where it has to handle header,
payload and footer generation as well as fragmentation into Data Link Layer Containers.
The ASE communicates with the Data Link Layer via the primitives defined in 5.6.1.
For a specific timeout dependent on the stream type andapplication, the ASE shall indicate a “data
starve event”, when expected application data units are not being received, in the register 3.6.2.
