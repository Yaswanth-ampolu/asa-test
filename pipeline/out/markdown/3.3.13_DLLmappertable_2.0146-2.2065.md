3.3.13DLLmappertable (2.0146-2.2065)
The mapper table at its maximum size for 64 DLP_TX is distributed over 1920 registers, three per
mapper table line. The first register contains the bit mask as shown in Table 3-43.
Bit(s) Name | Description | R/W* Access** Privilege***
15:0 BitMask | Bit mask for mapper counter | RW O | RID
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security

0x0000 and register 2.0148 resets to 0x8000. This leads to a mapper configuration for sending local
OAM only.

The size of the mapper table depends on the number of implemented DLP_TX in the specific ASA
node. A minimum of 4 and a maximum of 10 mapper table lines per implemented DLP_TX is
supported. (INFORMATIVE: The selection of number of lines is up to the implementer. The mandated
limits of the range provide, on one hand, a minimum configurability and, on the other hand, allows
standarized handling of a maximum table size.)
