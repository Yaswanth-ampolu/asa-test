7.10.3.5Read Response Command
The payload of the Read Response command is identical to the Write command payload (see section
7.10.3.2).
The root node should implement a timeout watchdog (depending on the schedule cycle for this ASEP
and the application use case) and treat a timeout as a NACK (all zeros).

7.10.4I2S Data Mode
Data mode packet are just sent by the ASEP on the side of I2S TX in case the TX is also the (audio
timing) host.
In case, the I2S RX is (audio timing) host, the I2S TX side ASEP sends audio sample data only while the
I2S RX side ASEP sends time stamps only.
