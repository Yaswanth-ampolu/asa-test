# 5.5.3.3 ReadError

5.5.3.3 ReadError
The Address format for bytes n+1 to n+3 is shared with the Read command 5.5.3.1.
Byte Bit(s) Name | Description
n+4 7:0 | reserved
n+5 7:0 | ErrorCode | 0x00: Address does not exist
0x01: Access not allowed
0x02..0xFF: reserved
