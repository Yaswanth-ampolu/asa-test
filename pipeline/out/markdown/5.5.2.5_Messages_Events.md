# 5.5.2.5 Messages/Events

5.5.2.5 Messages/Events
OAMHEADER_DECODE_ERR event signaling, that OAMframeID received is not as expected or
OAM header cannot be decoded
OAMHEADER_DUPLID_ERR | OAMframeID in header is smaller than rxOAMframeID+1 (or
smaller than nID. rxOAMframeID+1 in case of root node)
OAMHEADER_MISSID_ERR | OAMframeID in header is larger than rxOAMframeID+1 (or larger
than nID. rxOAMframeID+1 in case of root node)
OAMPAYLOAD_DECODE_ERR event signaling, that one or more CADs in the payload could not
be decoded
