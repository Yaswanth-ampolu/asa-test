# 6.4.3.1 KeyEx.install_UUID (ID: 0x00)

6.4.3.1 KeyEx.install_UUID (ID: 0x00)
This primitive is used to install the UUID.
The ID of this primitive shall be 0x00.
This function shall only be executable once.
If the UUID has been written before, the primitive shall return the Error Code 0x20 and shall not
change the UUID.
The request shall contain the following parameters:
Parameter | Length (bits) Enc. Auth. Description
UUID | No No The UUID to be written in the target
device.
Table 6-5: Request (ID 0x00)
The response shall contain the following parameters:
Parameter | Length (bits) Enc. Auth. Description
Status | No No See section 6.4.1.3
Relevant Codes: 0x00, 0x20, 0x21, 0xFF
Table 6-6: Response (ID 0x00)
