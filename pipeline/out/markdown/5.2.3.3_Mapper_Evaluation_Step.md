# 5.2.3.3 Mapper Evaluation Step

5.2.3.3 Mapper Evaluation Step
The evaluation step is executed for each container transmit opportunity. This section is a description
of a mandatory functional behavior based on the configured register values. However, it does not
mandate an implementation.
LINE is a combination of three consecutive registers holding BitMask, CompareValue,
DLP_TX_ID_toSend as illustrated in Table 3-46.
LINES is an ordered subset of Table 3-46.
Starting with first LINE, the Counter is bit-wise AND-concatenated and the result is compared to
CompareValue. If the comparison yields FALSE, the next LINE is tried. If the comparison yields TRUE,
the DLP_TX_ID to be sent has been found in that LINE and the remainder of LINES is not evaluated.
Lastly, the Counter is incremented and it is checked, whether it exceeds its range. If this is the case, it
is reset to CounterMin.
If no LINE has evaluated TRUE, the default value DLP_TX_ID=0 (OAM) is used.
