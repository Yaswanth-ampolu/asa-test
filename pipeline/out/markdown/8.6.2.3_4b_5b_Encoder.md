# 8.6.2.3 4b/5b Encoder

8.6.2.3 4b/5b Encoder
The 4b/b5 encoding process maps 4 bits of data to a 5 bit code word as depicted in the following
table:
4b/5b code | 4b/5b code
Data[3:0] | Data[3:0]
word [4:0] | word [4:0]
Table 8-14: 4b/5b Encoding
The 4b/5b code also contains the following control symbols:
Symbol | 4b/5b code | Description
word [4:0]
H | Halt
I | Idle
J | Start #1
K | Start #2
L | Start #3
Q | Quiet
R | Reset
S | Set
T | Terminate (End)
