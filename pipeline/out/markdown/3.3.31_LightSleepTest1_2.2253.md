# 3.3.31 LightSleepTest1 (2.2253)

3.3.31LightSleepTest1 (2.2253)
This register only exists, when (optional) LightSleep is implemented.
This register is intended for test purposes only. It can be used to trigger a root node to mediate and
execute LightSleep with the link partner.
Bit(s) Name | Description | R/W* Access** Privilege***
15:13 | reserved
LightSleep Test triggered by writing a 1 | SC L | RID
test trigger
11:0 LightSleep uint | RW L | RID
test | Number of TDD cycles to sleep (see
SleepCycles also 5.5.3.10)
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
