# 4.2.1 PCS Reset Function

4.2.1 PCS Reset Function
The PCS reset function initializes all PCS functions including all LFSR and the registers described in
section 3.2. The PCS reset is executed at Power-On state.
The PCS reset is also executed at Fail state unless otherwise defined for a particular register or
function.
Soft Reset through register (see section 3.2.7) is a subset of PCS reset as Soft Reset does not impact
configuration values.
