# 7.6.1 Layer 2 Ethernet Packet Types

7.6.1 Layer 2 Ethernet Packet Types
The ASEP Ethernet packet header is shown in Table 7-31.
Byte Bit(s) Name | Description
m +1 | ETH-CRCflag | 1: Ethernet CRC is contained in the payload
HB
0: Ethernet CRC has been cut from payload
m +1 6:0 | packet_length[14:8] Total length of the payload in bytes
HB
m +2 7:0 | packet_length[7:0]
HB
packet_length is mandatory to be set, when the
ASEP Ethernet packet starts and ends in the same
DLL container. If an ASEP Ethernet packet spans
more than one DLL container, packet length is
optional to be set
0x00 denotes an unset packet_length
