6.4.3.11KeyEx.install_BK_encrypted_by_DK_1_only (ID: 0x23)
This primitive is used to install the Binding Key persistently without the knowledge of the DK_0.
The ID of this primitive shall be 0x23.
This function shall be executable multiple times but may be limited by the capabilities of the devices.
The IV and ICV shall only be present, if the Status is OK (0x00).
The device shall check, if the DK_0 was already written and abort with an error (0x40: Device Key
Part 0 missing), if this is NOT the case. Keep in mind that the DK_0 has to be not known to run this
primitive.
The device shall check, if the DK_1 was already written and abort with an error (0x41: Device Key
Part 1 missing.), if this is NOT the case.
The device shall install the BK using this primitive, if the BK was written before or if the BK was not
written before.
The device shall generate the IV based on the construction rules in section 6.4.1.4.
The device shall generate the ICV based on the construction rules in section 6.4.1.6.
