Table 7-65: ASEP eDP–AUX Packet Payload
7.9.3.2.4 Main Link–8b10b Plain Lane Mode
It is recommended, that the payload of one packet contains all data of a single line of the full frame.
Byte | Bit(s) Name | Description
m +1 | 4:2 | Reserved
HB
m +1 | 1:0 | Lane Count | 0: 1 lane
HB
1: 2 lanes
2: 4 lanes
m +2 | 7:0 | Length[15:8] | Length of payload in 10bit symbols
HB
m +3 | 7:0 | Length[7:0]
HB
Table 7-66: ASEP eDP–Main Link Data Packet (8b10b Plain Lane Mode) Header
In 1-Lane payload, a multiple of four 10bit payload symbols are coded. If the fragment of DP data is
not divisible by 4, it is padded with zeros.
Byte | Bit(s) Name | Description

HB

HB

HB

HB

END
or zero-padding
m | 7:0 | Payload_L-1[7:0]
END
Table 7-67: ASEP eDP–Main Link Data Packet (8b10b Plain Lane Mode) 1-Lane Payload
In 2-Lane payload, a multiple of two 10bit payload symbols per lane are coded. If the fragment of DP
data is not divisible by 2, it is padded with zeros.
