# 1.3.9 Downstream (Dn)

1.3.9 Downstream (Dn)
Downstream direction with Downstream transmitter and Downstream receiver make up the high
bandwidth part of the ASA asymmetric half-duplex communication. It is abbreviated as Dn.
1.3.10Upstream (Up)
Upstream direction with Upstream transmitter and Upstream receiver make up the low bandwidth
part of the ASA asymmetric half-duplex communication. It is abbreviated as Up.
1.3.11Data Link Layer Container
One fixed size unit (per direction Downstream and Upstream) of the time division multiplex scheme
in a point-to-point ASA link.
1.3.12Near-side
A node is near-side to the root node, when OAM containers from the root node are directly coming
through the PLP_RX of that same node.
1.3.13Far-side
A node is far-side to the root node, when OAM containers from the root node have to pass another
node in the same device first to get to the same node.
1.3.14Clock Leader
In ASA the Clock Leader is located in the root node. It is the one node, which is not adjusting its PTB
clock to another node in the SerDes branch, but is providing the reference clock for the SerDes
branch.
1.3.15Local Clock Leader
The Local Clock Leader is the Far-side node on a Branch-Device, which is providing the PTB reference
clock towards the Leaf Nodes. There is a local clock leader for each point-to-point link. In a Branch
Device, each Far-side Node is a Local Clock Leader.
1.3.16Clock Follower
The clock follower is the Near-side node on a Branch-Device or Leaf Node, which is following the PTB
reference clock. Any non-root node device can have only one single Clock Follower on a particular
ASA Branch Device. There is a single follower at the Near-side of each P2P link.
