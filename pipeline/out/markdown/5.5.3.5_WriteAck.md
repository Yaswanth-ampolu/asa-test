# 5.5.3.5 WriteAck

5.5.3.5 WriteAck
The Address format for bytes n+1 to n+3 is shared with the Read command 5.5.3.1.
Byte Bit(s) Name | Description
n+4 7:0 | reserved
n+5 7:0 | ReturnCode | 0x00: reserved
0x01: Write successful
0x02: Write fail
0x04: Access not allowed (RO only register)
0x06: Access not allowed (Authentication)
0x08: Address does not exist
0x03, 0x05, 0x07,0x09..0xFF: reserved
