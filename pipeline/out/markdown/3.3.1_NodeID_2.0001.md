# 3.3.1 NodeID (2.0001)

3.3.1 NodeID (2.0001)
Bit(s) Name | Description | R/W* Access** Privilege***
15:5 | reserved
4:0 nodeID | Unsigned integer | RW O | RID
0 means, that nodeID is unset
1 identifies the root node
2-31 are leaf nodes or branch
device nodes
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
