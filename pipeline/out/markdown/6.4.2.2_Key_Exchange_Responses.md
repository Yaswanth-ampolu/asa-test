# 6.4.2.2 Key Exchange Responses

6.4.2.2 Key Exchange Responses
Informational: Key Exchange Responses use the OAM Command 0x7E which is reserved for Security.
For responses the OAM structure mapping shall be as follows (Bytes counted after the OAM Header):
Byte | Bit(s) | Value | Description
CADnext
6:0 | 0x7D | Command
7:0 | ID | Primitive ID
2 … n | 7:0 | Parameters | Primitive Parameters
