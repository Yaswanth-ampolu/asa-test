# 6.4.1.9 Ordering of repeatable fields (used in Status_LK)

6.4.1.9 Ordering of repeatable fields (used in Status_LK)
Parameters and return values for primitives regarding Link Keys always shall order the repeatable
fields in ascending order of the nodeIDs, to which they belong.
Nodes, which have their security policy set to none, have to be listed with all zero values.
