# 4.2.3.3 RS-FEC decoding

4.2.3.3 RS-FEC decoding
The PCS Receive function shall check the integrity of the RS-FEC parity bits defined in 4.2.2.4. If the correction
fails, the RS-FEC frame is invalid. Statistics shall be kept in the registers described in 3.2.16 and 3.2.13.
For SG1 and SG2, only the integrity check is mandatory, the correction is optional. If parity is only checked, but
no bit errors are corrected, an RS-FEC frame failing the parity check is also invalid.
