# 8.1.3 ASA MLE Registers

8.1.3 ASA MLE Registers
ASA Registers in sections 3.1 and 3.2 (where referenced by shared section 4 subchapters) also apply
to ASA Motion Link Ethernet.
Additional registers are defined in 3.2 for addresses 1.0020 onwards for MLE (to be used instead of
equivalent ML registers).
See also section 3.8 for an exact list of applicable MLE registers.
