# 5.5.2.2 Variables

5.5.2.2 Variables
nID.txOAMframeID: internal variable, last OAMframeID used by root node in OAM frame to
nodeID nID, initializes to 0
nID.rxOAMframeID | internal variable, last OAMframeID received by root node in OAM frame
from nodeID nID, initializes to 0
txOAMframeID: | internal variable, last OAMframeID used by non-root node in OAM frame
to root, initializes to 0
rxOAMframeID: | internal variable, last OAMframeID received by non-root node in OAM
frame from root, initializes to 0
lastCADcmd: | last CAD put into the OAM frame payload being constructed
CADrespFIFOlvl: | indicating fill level of CAD response FIFO in non-root node, can be
“empty” or “not empty”, initializes with “empty”
CADcmdFIFOlvl: | indicating fill level of CAD command FIFO in root node, can be “empty” or
“not empty”, initializes with “empty”
