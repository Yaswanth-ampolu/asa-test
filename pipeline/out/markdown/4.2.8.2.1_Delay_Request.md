# 4.2.8.2.1 Delay Request

4.2.8.2.1 Delay Request
Clock follower only sends back Delay Request messages. This is not explicitly coded since there is no
other message from the clock follower.
For the Delay Request message, the time stamp is identical to the lower 14 bits of PTBclk (see 3.3.19)
at the instant, when the first symbol of the first physical layer block of this TDD burst being sent will
pass the local MDI.This time stamp is also kept in the Clock Follower as “t_PTB_tx” (see4.2.8.3.3).
If PTBclk is not locked or not running, the time stamp is undefined.
Status indicates that follower is locked and time stamp is good. See 4.2.8.4 for a detailed description
of the lock state.
INFORMATIVE: The Delay Request messages time stamp is not required by the clock leader for any
calculation. However, it can be used to sanity check the status being provided.
