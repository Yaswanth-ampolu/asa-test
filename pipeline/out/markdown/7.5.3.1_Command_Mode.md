# 7.5.3.1 Command Mode

7.5.3.1 Command Mode
In I2C Configuration mode, the lower bits of the command byte are defined as shown in Table 7-26.
Byte Bit(s) Name | Description
m +2 4:3 | Reserved
HB
m +2 2:0 | Configuration | 000: Write command mode (I2C Master)
HB
command mode | 001: Read command mode (I2C Master)
010: Ack/Nack mode (I2C Slave)
011: Read response mode (I2C Slave)
1xx: Reserved
m +3 7:4 | Reserved
HB
m +3 3:0 | No. of I2C addresses 0: reserved
HB
Number of I2C slave addresses in this message
