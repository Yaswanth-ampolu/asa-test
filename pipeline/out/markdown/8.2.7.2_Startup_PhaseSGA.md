# 8.2.7.2 Startup PhaseSGA

8.2.7.2 Startup PhaseSGA
A startup PhaseSGA burst txSGA_Up or txSGA_Dn is a concatenation of a single resynchronization
header as defined in 4.2.2.3 and physical layer blocks as defined in 8.2.2.4 as in normal mode TDD
(8.2.2.2) with two differences: firstly, the input data to the physical layer block is equal to all zeros
except for the second to last physical layer block in each burst (see below). Secondly, the number of
physical layer blocks per burst in Table 8-2 is replaced by:
