# 2.4 ASA Transceiver State Diagram

The Startup also supports node enumeration and enables configurability of the entire SerDes branch
from the root node.
The optional feature of Light Sleep enables a duty cycling of the Physical Layer between active and
disabled state in the time scale of typical sensor and display event periods.
The Data Link Layer supports multiplexing and demultiplexing of application and internal data
streams onto and from the Physical Layer. The multiplexing of fixed size containers is controlled by a
programmable, deterministic, cyclic time-division access mechanism dubbed a Mapper. The
demultiplexer supports forwarding of streams in a SerDes Branch tree topology as well as stream
duplication (multicast up to 4 nodes). Data Link Layer behavior is configured through ASA registers
(see section 3) accessed by the ASA internal communication protocol OAM (Operations,
Administration, Maintenance). See section 5.
ASA specifies a mandatory logical clock throughout the SerDes Branch called PTB (Precision Time
Base).
The Data Link Layer optionally supports link-based security with authentication and encryption (see
6).
ASA specifies ASA-internal exchange formats of common application data types or interfaces for the
payload of Data Link Layer containers. See section 7.
An ASA device implements a subset of the ASEP types relevant to the application, where each ASEP
type may be present with one or more instances.

Power On state is entered at the time, when a stable power supply to the device containing the ASA
node is established (such that volatile memory is persistent). The duration from entering the Power-
On state to entering Normal Mode state shall be 100ms or less. Of these 100ms, a maximum of up to
30ms can be spent in Power-On state.
The state diagrams for Startup and startup-triggered Test Mode are described in 4.3.3.1. OAM config
is described in 5.9. The state diagrams of Light Sleep are described in 5.8.3.
Fail State is entered when Link Loss spans 3 consecutive TDD bursts or more (see also 3.2.13).
