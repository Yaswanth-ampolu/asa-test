# 5.5.3.10 LSannounce

5.5.3.10LSannounce
There is no address for this command. Instead, four parameters are provided.
Byte Bit(s) Name | Description
n+1 7:0 | PTBbedtime[47:40]
n+2 7:0 | PTBbedtime[39:32]
n+3 7:0 | PTBbedtime[31:24]
PTB time stamp, at which the announcing node
wants to go to Light Sleep
n+4 7:0 | PTBbedtime[23:16]
n+5 7:0 | PTBbedtime[15:8]
n+6 7:0 | PTBbedtime[7:0]
n+7 7:4 | Reserved
n+7 3:0 | SleepCycles[11:8]
Number of TDD cycles, the announcing node
wants to sleep (this includes restart time)
n+8 7:0 | SleepCycles[7:0]
n+9 7:0 | RestartCycles1G[7:0] Number of Phase1G patterns required to restart
n+10 7:0 | RestartCyclesSGx[7:0] Number of PhaseSGA/B/C patterns required to
restart
n+11 | Reserved
