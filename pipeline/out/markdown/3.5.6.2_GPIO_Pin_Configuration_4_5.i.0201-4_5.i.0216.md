# 3.5.6.2 GPIO Pin Configuration (4/5.i.0201-4/5.i.0216)

3.5.6.2 GPIO Pin Configuration (4/5.i.0201-4/5.i.0216)
There are 16 configuration registers, one for each of the maximum number of GPIO pins per ASEP on
one DLP_TX/DLP_RX.
Bit(s) Name | Description | R/W* Access** Privilege***
15:8 | Reserved
Pin availability 0: not available | RO O | RID
1: available
GPIO signal 0: GPI : Leaf (ASE)→Root (ASD) RW O | RID
direction | 1: GPO: Root (ASE)→Leaf(ASD)
5:3 GPIO pin | only valid for available pins | RW O | RID
default / reset 000: floating
behavior | 001: pull-down to low state
010: pull-up to high state
111…011 : userdefined
Shall be asserted during Power-
On / Init state (see section 2.4)
Informative: behavior should be
asserted within 10ms of stable
power supply to the device
2:1 GPO drive | only valid for available output RW O | RID
mode | pins
00: push / pull mode
01: open drain
10, 11: user defined
GPIO enable 0: disable | RW O | RID
1: enable
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
