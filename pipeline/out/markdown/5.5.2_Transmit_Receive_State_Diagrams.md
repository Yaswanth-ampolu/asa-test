# 5.5.2 Transmit/Receive State Diagrams

5.5.2 Transmit/Receive State Diagrams
The OAM transmit and receive is linked to the DLL Transmit Process (see 5.2.1) and the DLL Receive
Process (see 5.3.1) and their primitives.
The frame based OAM communication is stateful as described in this 5.5.2. The generation and effect
of CADs, response to CADs and error handling is described in 5.5.3.
