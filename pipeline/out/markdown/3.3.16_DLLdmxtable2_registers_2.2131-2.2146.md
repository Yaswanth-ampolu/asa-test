# 3.3.16 DLLdmxtable2 registers (2.2131-2.2146)

3.3.16DLLdmxtable2 registers (2.2131-2.2146)
The demultiplexer table part02 is distributed over 16 registers, one per two targetID. Each register
has the format as shown in Table 3-52.
Bit(s) Name | Description | R/W* Access** Privilege***
Reserved
IDvalid | 1: targetID set, 0: not set | RW O | RID
13:8 DLP_RX_ID DLP_RX_ID to demultiplex to | RW O | RID
Reserved
IDvalid | 1: targetID set, 0: not set | RW O | RID
5:0 DLP_RX_ID DLP_RX_ID to demultiplex to | RW O | RID
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
