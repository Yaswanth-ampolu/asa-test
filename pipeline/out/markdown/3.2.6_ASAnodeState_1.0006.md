# 3.2.6 ASAnodeState (1.0006)

3.2.6 ASAnodeState (1.0006)
Bit(s) Name | Description | R/W* Access** Privilege***
15:4 | Reserved
3:0 ASA Node State 0: PowerOn / Init | RO O | RID
1: Startup (initial startup or
coming back from Light Sleep)
2: OAM Config
3: Normal Mode
4: Test Mode
5: Light Sleep
(further refined in 3.3.29)
6: Fail
7: Deep Sleep
Other values reserved
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
