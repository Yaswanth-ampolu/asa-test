# 3.5.1.1 Full Packet ID (4/5.i.0001, 4/5.i.0002, 4/5.i.0003)

3.5.1.1 Full Packet ID (4/5.i.0001, 4/5.i.0002, 4/5.i.0003)
Each fullPacketID[47:0] is associated with each DLP_TX_ID and each DLP_RX_ID port and therefore in
the ASEP address space, but managed by the DLL.
It is incremented for each container sent for this DLP_TX, whereas the lower 5 bits fullPacketID[4:0]
are copied into the container header. See 5.2.2.4.
At the receiver side (sinking DLP_RX), the fullPacketID[47:0] is incremented for every correctly
received container. See 5.3.2.1.
The register fullPacketID resets to 0.
For the special case of the FoFa, where ASEP Stream Type is“Return OAM”or“ForwardData”, the
register has no function. See 5.4.
