# 4.2.8.4.4 Counters

4.2.8.4.4 Counters
cnt_dlyRply_received: Integer value, that counts the number of delay reply messages received,
saturates at value equal to ptb_ACQ_window
cnt_follow_received: Integer value, that counts the number of follow messages received,
saturates at value equal to ptb_ACQ_window
