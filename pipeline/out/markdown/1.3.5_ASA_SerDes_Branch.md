# 1.3.5 ASA SerDes Branch

1.3.5 ASA SerDes Branch
An ASA SerDes Branch is a multitude of ASA devices connected in a tree (non-loop) topology and
made up of one or more point to point connections between ASA nodes of separate ASA devices.
