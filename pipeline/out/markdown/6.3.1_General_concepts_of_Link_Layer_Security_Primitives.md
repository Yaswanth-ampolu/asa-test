# 6.3.1 General concepts of Link Layer Security Primitives

6.3.1 General concepts of Link Layer Security Primitives
The Link Layer Security shall provide link layer security. That is security between the two nodes on a
single link. This does not include end-to-end security.
The Link Layer Security can be used in two modes:
1. “Authentication Only”mode.
2. “Authentication and Encryption” mode.
While the first mode is required for all devices implementing Security, the second mode is optional.
Informative: Since the overhead of additionally implementing the second mode is very small,
implementing both is strongly recommended.
