# 5.5.2.4 Functions

5.5.2.4 Functions
createOAMheader(): create an OAM header with nID.txOAMframeID, based on events
OAMHEADER_DECODE_ERR, OAMPAYLOAD_DECODE_ERR,
OAMHEADER_DUPLID_ERR and OAMHEADER_MISSID_ERR, as well as
current state of ASA registers; error shall only be cleared, once they have
been reported through OAM frame header
fillCADresponseFIFO(): put response CADs into CADreponse FIFO (in the same order as they have
been evaluated)
readCADrespFIFO(): read one CAD response command from the CADresponseFIFO to put into
OAM frame
decodeNodeID(header): decode nodeID from DLL container header (for root node OAM)
checkOAMheader(nID): check OAM header for decodability, correct OAMframeID (for nID in case
or root node) and create event OAMHEADER_DECODE_ERR,
OAMHEADER_DUPLID_ERR, OAMHEADER_MISSID_ERR, if applicable
fillLongAtomFIFO(): | put CADs from current OAM frame payload into LongAtomFIFO (in the
same order as they are in the payload)
flushLongAtomFIFO(): empty LongAtomFIFO
evalLongAtomFIFO(): evaluate CADs in LongAtomFIFO (in the same order they have been put in)
