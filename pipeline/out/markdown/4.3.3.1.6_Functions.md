# 4.3.3.1.6 Functions

4.3.3.1.6 Functions
start1Gstat(): | sets the status in the startup-1G-Phase info field and transmit one
Phase1G burst
start1Gtestcmd(): | sets the test command in the startup-1G-Phase info field and transmit one
Phase1G burst
startSGAstat(): | sets the status in the startup-PhaseSGA info field and transmit one
PhaseSGA burst
startSGAtestcmd(): | sets the test command in the startup-PhaseSGA info field and transmit
one PhaseSGA burst
startSGBstat(): | sets the status in the startup-PhaseSGB info field and transmit one
PhaseSGB burst
startSGCstat(): | sets the status in the startup-PhaseSGC info field and transmit one
PhaseSGC burst
txDisable(): | put own transmitter in disable state (see section 4.4.2.7)
