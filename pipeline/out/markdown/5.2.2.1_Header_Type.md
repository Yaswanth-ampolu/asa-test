# 5.2.2.1 Header Type

5.2.2.1 Header Type
If only the targetID0 is set in 3.3.6, the basic header type is used.
If more than targetID0 is set in 3.3.6, the extended header type is used.
In case of OAM, the targetID or targetIDs are supplied by primitive 5.6.1.3.
