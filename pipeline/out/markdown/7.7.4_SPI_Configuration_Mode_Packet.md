# 7.7.4 SPI Configuration Mode Packet

7.7.4 SPI Configuration Mode Packet
SPI configuration mode packet is used to transfer SPI configuration information from ASA register in
ASA node interfacing to SPI master to ASA registers in ASA node interfacing to SPI slave.
The SPI ASE interfacing to the SPI master device issues the write/read command to the SPI ASE/ASD
in the node interfacing to the SPI slave devices. The SPI ASE/ASD interfacing to the SPI slave devices
in turn responds with Ack/Nack command to the Write command and with Read Response command
to the Read command.
