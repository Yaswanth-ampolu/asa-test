# 6.4.3.2 KeyEx.read_UUID (ID:0x02)

6.4.3.2 KeyEx.read_UUID (ID:0x02)
This primitive is used to read the UUID.
The ID of this primitive shall be 0x02.
This function shall be executable multiple times.
The request shall contain the following parameters:
Parameter | Length (bits) Enc. Auth. Description
Table 6-7: Request (ID 0x02)
The response shall contain the following parameters:
Parameter | Length (bits) Enc. Auth. Description
Status | No No See section 6.4.1.3
Relevant Codes: 0x00, 0x30, 0xFF
UUID | No No The UUID of the target device
Table 6-8: Response (ID 0x02)
