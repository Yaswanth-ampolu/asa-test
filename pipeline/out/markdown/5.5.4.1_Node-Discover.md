# 5.5.4.1 Node-Discover

The enumeration is continued further out behind this far-side node by sending a Node-Discover
message with one targetID equal to the far-side nodeID and one targetID=0.
It is the responsibility of the root node to update the Demultiplexing Table 2 (see 3.3.16) in
previously enumerated nodes to list the nodeIDs of newly discovered nodes in the topology.
