# 5.5.1 Frame Structure

5.5.1 Frame Structure
An OAM frame consists of a 24 byte header (shown in Table 5-2) and conditionally one or more
Command-Address-Data structures as defined in 5.5.3. The principal structure of an OAM frame is
shown in Figure 5-6.
The header contains an OAMframeID, OAM error flag and valid as well as a constantly passed on
status of PTB and a short list of mandatory and implementer-defined link health registers. The
header also contains a CADnext flag to signal, whether there is a command present after the header.
The MSB in the first byte of any CAD indicates, whether there is an additional CAD present.
