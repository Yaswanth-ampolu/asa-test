# 5.8.1.2 Check by Root

5.8.1.2 Check by Root
The root node shall collect all LSconfirm messages from affected nodes and evaluate the maxima
RestartCycles1G_f=max(RestartCycles1G_a_1, … , RestartCycles1G_a_n) and
RestartCyclesSGx_f=max(RestartCyclesSGx_a_1, … , RestartCyclesSGx_a_n).
Based on these values, the following conditions shall be met:
- PTB is locked
- SleepCycles*phSGx_TIME - (RestartCycles1G_f*ph1G_TIME +
RestartCyclesSGx_f*phSGx_TIME) > 25,000 … estimation of own sleep time beforerestart
has to be larger than 100µs
- PTBbedtime–PTBclk > 12,500 … announced time to go to sleep has to be at least 50µs into
the future
If any of these conditions is not met, LSpossible is FALSE.
Light Sleep is allowed to be denied any time.
PTBalarmclock = PTBbedtime + SleepCycles*phSGx_TIME - (RestartCycles1G_f*ph1G_TIME +
RestartCyclesSGx_f*phSGx_TIME)
