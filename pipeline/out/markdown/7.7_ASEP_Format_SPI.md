# 7.7 ASEP Format: SPI

Buffers are required to adapt input Ethernet line rate to ASA allocated bandwidth. Buffers are also
required to adapt ASA allocated bandwidth to output Ethernet line rate.
ASEP Format: SPI
This ASEP is based on segmenting SPI bus activity into fixed size chunksof length “SPI data
conversion period”, where each chunk is transmitted in one ASEP packet. The response to the SPI
master has a defined latency and SPI access has to be handled in a special way. See 7.7.1 for cycle
time definitions and 7.7.2 for requirements on SPI interface.
Informative: The SPI interface pin names are Serial Clock SCK, Master In Slave Out MISO, Master In
Slave Out MOSI and Chip Select CS.
