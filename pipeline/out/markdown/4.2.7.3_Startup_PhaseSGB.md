# 4.2.7.3 Startup PhaseSGB

4.2.7.3 Startup PhaseSGB
A startup PhaseSGB burst txSGB_Up or txSGB_Dn is a concatenation of a single resynchronization
header as defined in 4.2.2.3 and physical layer blocks as defined in 4.2.2.4 as in normal mode TDD
(4.2.2.2) with two differences: firstly, the input data to the physical layer block coding d_plp_tx<7:0>
is equal to zero except for the last physical layer block in each burst (see below). Secondly, the
number of containers per burst in Table 4-2 is replaced by:
Dn Speed Grade
Number of physical layer blocks
Table 4-19: Downstream: physical layer blocks per startup PhaseSGB burst
The first bit being sent of the resynchronization header is its LSB. The first bit being sent of the
physical layer block (except the last one) is its MSB. The first bit being sent of the last physical layer
block is its LSB.
The number of symbols in the quiet gap is the same as in normal mode (see Table 4-4).
The last physical layer block is identical to PhaseSGA as defined in Equation 4-12, Equation 4-13 and
Equation 4-14.
The PCS Scrambler is being run as described in 4.2.2.5.1 for all Downstream Speed Grades and as
described in 4.2.2.5.3 for all Upstream Speed Grades.
For all Speed Grades, scrambled symbols are mapped to PAM2 as in normal mode (4.2.2.6).
