# 7.3.3 Common ASEP Format Basics per Footer

7.3.3 Common ASEP Format Basics per Footer
An ASEP format may or may not employ a CRC checksum over one ASEP packet, which gets sent and
may get fragmented into several Data Link Layer Containers. A CRC checksum might also be
separately generated for ASEP header and ASEP payload.
If the ASEP format does employ a CRC check, the ASD shall check the consistency of the data after
reassembly of the received fragments and shall indicate an error by incrementing 3.7.1.
ASEP Format: Video Data
The video format can provide all necessary information for camera and for display applications.
