# 4.2.8.3.1.1 PTB initial copy

4.2.8.3.1.1 PTB initial copy
On the reception of an OAM frame, if the local PTB is unlocked, the PTBclk register (see 3.3.19) is
overwritten with the entire PTBclk value of the received OAM header (see Table 5-2).
