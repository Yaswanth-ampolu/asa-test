# 6.4.1.3 Status and Error Codes for KeyEx primitives

6.4.1.3 Status and Error Codes for KeyEx primitives
The 8bit status codes shall be defined as follows:
•
0x00: OK.
•
0x10: Nonce Computation not finished yet.
•
0x11: Authentication failed.
•
0x12: Wrong UUID.
•
0x20: Already written before and can only be written once.
•
0x21: Written but verify failed.
•
0x30: UUID not written to device yet.
•
0x40: Device Key Part 0 not written to device yet.
•
0x41: Device Key Part 1 not written to device yet.
•
0x42: Binding Key not written to device yet.
•
0x43: Maximum number of writes reached.
•
0x44: Link Key not written to device yet.
•
0x50: Not enough LKs.
•
0x51: Too many LKs.
•
0x52: Unsupported LK size.
•
0x53: Unsupported Salt size.
•
0x60: Unsupported Key Slot
•
0x61: Key Slot empty
•
0x62: Key Slot deactivated before
•
0xFF: Unspecified error (optional).
Relevant Status / Error codes per primitive are shown in Appendix A: KeyEx Primitive–Mapping of
Status Codes.
