# 7.10.2 I2S Packet Header

7.10.2I2S Packet Header
The I2S ASEP header format is shared for all packet modes.
Byte | Bit(s) Name | Description
m +1 | I2S packet mode 0: I2S configuration mode
HB
1: I2S data mode
m +1 | 6:0 | I2S packetID | Each ASEP keeps two independent I2S
HB
packetID counters, one for I2S configuration
mode packets, one for I2S data mode packets.
Both I2S packetID counters start from 1
I2S packetID valid range is 1-120, an
increment from 120 rolls over to 1
Values 0, 121-127 are reserved
I2S configuration mode: The host side
increments the I2S packetID with each packet
sent; the slave side copies the host sides
packetID into this field of the response
I2S data mode: I2S packetID is incremented
for each packet sent
