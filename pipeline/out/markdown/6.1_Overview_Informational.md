# 6.1 Overview (Informational)

Overview (Informational)
The Security functionality of this standard is made up by two high level components:
•
Key Exchange Entity–which is responsible for handling and exchanging keys. This
component is responsible for storing the keys securely. Key Exchange messages are
transported by the OAM channel.
•
Link Layer Security–which is responsible for protecting messages using keys provided by the
Key Exchange Entity. Protection means authentication and integrity protection. Encryption of
containers is an optional feature.
