# 6.4 Key Exchange

▪ Salt
▪ “Next Link Layer TX AEAD Invocation Counter”
o Increment “Next Link LayerTX AEAD Invocation Counter” by 1
o Check IV “Link Layer TX AEAD Invocation Counter” regarding margin to overflow (the
remaining value range of the counter before overflow):
▪ If the margin to overflow drops below 10%, call primitive
KeyEx.report_status_LK (0x81).
▪ If the margin to overflow drops below 5%, call primitive
KeyEx.report_status_LK (0x81).
▪ Upon reaching its maximum value, the current Key Slot shall be deactivated,
and the other key slot shall be selected. Then, the primitive
KeyEx.report_status_LK (0x81) shall be called.
•
Process Container Header, Counter and DLL Payload with AES-GCM or AES-GMAC based on
configuration
•
Construct Security Payload
o Add least significant 8 bits of the constructed IV as counter.
o Add processed DLL payload.
o Add ICV.
•
Call primitive 6.3.2.2.
