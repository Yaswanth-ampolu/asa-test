# 4.2.7.4 Startup PhaseSGC

4.2.7.4 Startup PhaseSGC
A startup PhaseSGC burst txSGC_Up or txSGC_Dn is a concatenation of a single resynchronization
header as defined in 4.2.2.3 and physical layer blocks as defined in 4.2.2.4 as in normal mode TDD
(4.2.2.2) with one difference: the input data to the physical layer block coding d_plp_tx<7:0> is equal
to zero except for the last physical layer block in each burst (see below).
The first bit being sent of the resynchronization header is its LSB. The first bit being sent of the
physical layer block (except the last one) is its MSB. The first bit being sent of the last physical layer
block is its LSB.
The number of symbols in the quiet gap is the same as in normal mode (see Table 4-4).
The last physical layer block is identical to PhaseSGA as defined in Equation 4-13 and Equation 4-14.
The PCS Scrambler is being run as described in 4.2.2.5.2 for Downstream Speed Grades 4 and 5, and
as described in 4.2.2.5.3 for all Upstream Speed Grades.
For Speed Grades 4 and 5 Downstream, scrambled physical layer block symbols and symbols of
Equation 4-13 are mapped to PAM4 as in normal mode (4.2.2.7), scrambled symbols of all Upstream
Speed Grades are mapped to PAM2 as in normal mode (4.2.2.6).
