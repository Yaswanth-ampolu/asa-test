# 5.5.3.8 LongAtomClose

5.5.3.8 LongAtomClose
There is no Address or Data for this command. This command signals (at the end of an OAM frame),
that the Write commands buffered before with LongAtom shall be written after the end of the TDD
burst, in which this LongAtomClose has been received.
Byte Bit(s) Name | Description
n+1 7:0 | reserved
