# 7.8.1 GPIO Packet Header

7.8.1 GPIO Packet Header
The GPIO ASEP header format is shared for all packet modes. GPIO packet IDs are a single sequence
of IDs over all packet modes.
Byte Bit(s) Name | Description
m +1 | GPIO packet mode 0: GPIO configuration mode
HB
1: GPIO data transmission mode
m +1 6:0 | GPIO packet ID | Starts at 1, incremented by 1 for every GPIO
HB
packet sent, wraps around from 127 to 1
0: reserved
