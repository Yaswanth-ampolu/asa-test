# 6.2.4 Link Keys

6.2.4 Link Keys
A Link Key (LK) is used to authenticate, integrity protect, and optionally encrypt messages on an ASA
link between two adjacent devices.
Link Keys shall be symmetric.
Link Keys shall not be stored persistently beyond the power cycle since this might affect overall
security (informative).
Link Keys shall be installed at least once in every power cycle.
Link Keys shall not be readable from outside the ASA nodes on the device (including OAM Channel).
