# 5.2.1 Data Link Layer Transmit Process

5.2.1 Data Link Layer Transmit Process
The Transmit Process in the DLL is cyclic with the occurrence of a physical layer block in the PCS
Transmit Process.
The following steps are executed (in the listed order), when DLL is triggered by 4.6.1.2:
a) Evaluation Step of the Mapper (see 5.2.3.3), which yields a DLP_TX_ID_toSend
b) That DLP_TX_ID is polled with primitive DLP_TX.indicateSlot (see 5.6.1.1)
c) Wait for a response on DLP with DLP_TX_ID
d) Construct container header, also depending on primitive replied (see 5.2.2)
e) If security is enabled:
1. Call primitive in LLS (see 6.3.2.1)
2. Wait for LLS to respond
i. In case of 6.3.2.2, continue with f)
ii. In case of 6.3.2.5, call 4.6.1.1 with an array of all zeros
f) Put DLL container to PLP_TX (see 4.6.1.1) while bit order inside bytes is the same (i.e.
d_plp_tx<7>,<0> is the MSB of the first byte of the DLL container header)
