# 4.2.2.1 PCS Transmit Process

4.2.2.1 PCS Transmit Process
The PCS transmit process creates TDD data bursts in normal mode, PMA training patterns during
startup and test patterns for test mode.
The PCS transmit process creates ASA physical layer blocks out of data obtained from PLP_TX
(d_plp_tx<7:0>). The resync header (see Figure 4-3), training patterns and test patterns are
generated by the PCS transmit process itself. An overview of the data flow is given in Figure 4-1.
