# 6.3 Link Layer Security

For unwritten Device Keys, 0x00 shall be used as key value.
Device Key sub-keys shall be only one-time writable.
Device Keys and Device Key sub-keys shall not be readable from outside the ASA nodes on the device
(including OAM Channel).
