# 6.4.4.2 UUID and Device Key Tier-1 Installation

6.4.4.2 UUID and Device Key Tier-1 Installation
In the Tier-1 production, a process similar to this and based on the OEM requirements shall be run
for a given device:
•
Generate a UUID and DK_0 using a usable scheme, so that both are unique.
•
Install a UUID using KeyEx.install_UUID
•
Install a DK_0 using KeyEx.install_DK_0_unencrypted
•
Handle the returned status of the calls.
