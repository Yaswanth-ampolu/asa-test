# 1.3.15 Local Clock Leader

1.3.15Local Clock Leader
The Local Clock Leader is the Far-side node on a Branch-Device, which is providing the PTB reference
clock towards the Leaf Nodes. There is a local clock leader for each point-to-point link. In a Branch
Device, each Far-side Node is a Local Clock Leader.
