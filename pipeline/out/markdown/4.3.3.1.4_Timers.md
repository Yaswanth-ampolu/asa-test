# 4.3.3.1.4 Timers

4.3.3.1.4 Timers
ph1G_root_rx_timer: Timer that is started on the last symbol of Phase1G pattern transmission
from root on the MDI with 200µs, and is stopped on the first symbol of a
successfully received pattern. When the timer reaches zero,
ph1G_root_rx_timer_done = TRUE. An undecodable info field is treated as
an expired timer.
ph1G_leaf_rx_timer: Timer that is started on the last symbol of Phase1G pattern transmission
from leaf on the MDI (or after resetting/modifying ph1G_retry_cnt) with
200µs, and is stopped on the first symbol of a successfully received
pattern. When the timer reaches zero, ph1G_leaf_rx_timer_done = TRUE.
An undecodable info field is treated as an expired timer.
phSGA_root_rx_timer: Timer that is started on the last symbol of PhaseSGA pattern transmission
from root on the MDI with 312ns, and is stopped on the first symbol of a
successfully received pattern. When the timer reaches zero,
phSGA_root_rx_timer_done = TRUE.
In case of a detected signal before expiration of the timer, but an
undecodable infofield, it is up to the implementation to either:
- Keep going and respond with status “TRAINING”
- Go to the FAIL_SGA_1 state to recommence the startup
phSGA_leaf_rx_timer: Timer that is started on the last symbol of PhaseSGA pattern transmission
from leaf on the MDI with 312ns, and is stopped on the first symbol of a
successfully received pattern. When the timer reaches zero,
phSGA_leaf_rx_timer_done = TRUE.
In case of a detected signal before expiration of the timer, but an
undecodable infofield, it is up to the implementation to either:
- Keep going and respond with status “TRAINING”
- Go to the FAIL_SGA_2 state to recommence the startup
phSGB_root_rx_timer: Timer that is started on the last symbol of PhaseSGB pattern transmission
from root on the MDI with 312ns, and is stopped on the first symbol of a
successfully received pattern. When the timer reaches zero,
phSGB_root_rx_timer_done = TRUE.

phSGB_leaf_rx_timer: Timer that is started on the last symbol of PhaseSGB pattern transmission
from leaf on the MDI with 312ns, and is stopped on the first symbol of a
successfully received pattern. When the timer reaches zero,
phSGB_leaf_rx_timer_done = TRUE.
In case of a detected signal before expiration of the timer, but an
undecodable infofield, it is up to the implementation to either:

- Go to the FAIL_SGB_2 state to recommence the startup
phSGC_root_rx_timer: Timer that is started on the last symbol of PhaseSGC pattern transmission
from root on the MDI with 312ns, and is stopped on the first symbol of a

ph1G_leaf_tx_test_timer: Timer that is triggered after loading test pattern and is started with 20ms.
When the timer reaches zero, ph1G_leaf_tx_test_timer_done = TRUE.
ph1G_root_tx_test_timer: Timer that is triggered after sending a test command and is started with
20ms plus inline runtime of respective triggered test (see section 4.4.1.1).
When the timer reaches zero, ph1G_root_tx_test_timer_done = TRUE.
phSGA_leaf_rx_test_timer1: Timer that is triggered after receiving test command and is started
with 20ms. When the timer reaches zero,
phSGA_leaf_rx_test_timer1_done = TRUE.
phSGA_leaf_rx_test_timer2: Timer that is triggered after stopping bit error tester and is started
with 20ms. When the timer reaches zero,
phSGA_leaf_rx_test_timer2_done = TRUE.
phSGA_root_rx_test_timer: Timer that is triggered after test command and is started with the
sum of phSGA_leaf_rx_test_timer1 and phSGA_leaf_rx_test_timer2 plus
inline runtime of respective triggered test (see section 4.4.1.2). When the
timer reaches zero, phSGA_root_rx_test_timer_done = TRUE.
