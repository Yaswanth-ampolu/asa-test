# 4.2.2.3.5 PTB Message Vector

4.2.2.3.5 PTB Message Vector
The m_ptb<15:0> for TDD bursts from clock leader (or local clock leader) to clock follower has the
fields shown in Table 4-8.
Bit(s) Name | Description
PTB command 0: follow
1: delay reply
PTB status | 0: not valid
1: valid (time stamp is usable for calculation)
13:0 TDDstamp | See 4.2.8.1
Table 4-8: PTB message from clock leader
The m_ptb<15:0> for TDD bursts from clock follower to clock leader has the fields shown in Table
4-9.
Bit(s) Name | Description
reserved, set to 0
PTB status | 0: not valid
1: valid (this follower is locked to clock leader, time stamp is usable
for calculation)
13:0 TDDstamp | See 4.2.8.2
Table 4-9: PTB message from clock follower
