# 4.4.1 Test Modes

4.4.1 Test Modes
All Transmitter and Receiver test modes can be triggered by (locally) writing to the register described
in 3.2.18 or by using the command in the respective info field of the startup (see 4.2.7). A test
initiated by writing the register is active until the register value is changed; a test initiated through
the startup info field is only active and non-interactive for a limited time, after which the device
under test cycles back to startup initialization (see 4.3.3.1). The duration to stay in the test is defined
separately for each test mode.
The S11 Termination test can only be activated by (locally) writing the register.
