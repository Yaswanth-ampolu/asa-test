5.5.3.14KeyExMsg
The KeyExMsg command is a special command that is used in the optional security feature for
communication with the KeyExchange entity. It is described in 6.4.
The KeyExMsg is always the only command in an OAM frame, if it is being used. Bit7 in the first CAD
byte is always 0 (see Table 5-3).
