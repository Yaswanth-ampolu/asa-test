# 7.6 ASEP Format: Layer 2 Ethernet Frame

ASEP Format: Layer 2 Ethernet Frame
For this ASEP, all Layer 2 headers and the full frame payload defined by IEEE802.1 are transported.
The Layer 2 header includes:
•
Destination MAC-Address
•
Source MAC-Address
•
Ethertype
•
VLAN-Tags (if present)
Transport of the Ethernet CRC (Frame Check Sum) is optional.
