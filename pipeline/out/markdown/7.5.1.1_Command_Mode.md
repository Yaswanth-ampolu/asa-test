# 7.5.1.1 Command Mode

7.5.1.1 Command Mode
In I2C byte mode, the lower bits of the command byte are defined as shown in Table 7-15.
Byte Bit(s) Name | Description
m +2 | I2C Data | 1: Data detected (payload byte follows)
HB
0: not detected (no payload byte)
m +2 | I2C Nack | 1: Nack detected
HB
0: not detected
m +2 | I2C Ack | 1: Ack detected
HB
0: not detected
m +2 | I2C Stop | 1: Stop detected
HB
0: not detected
m +2 | I2C Start/Restart | 1: Start/Restart detected
HB
0: not detected
Table 7-15: ASEP I2C–Byte mode command format
