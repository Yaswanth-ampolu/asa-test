# 6.4.3.5 KeyEx.read_status_keys_ext (ID: 0x07)

6.4.3.5 KeyEx.read_status_keys_ext (ID: 0x07)
This primitive is used to read the status of the keys installed and the status of the TX IVs on the
device securely.
The ID of this primitive shall be 0x07.
This function shall be executable multiple times.
The primitive shall transport the following Status_LKs_IVs struct:
•
Number of entries [8bit]
•
Array of Status_Node:
o Node [uint8]
▪ NodeID [7…3], Bitmask 0b11111000
▪ Reserved [2…0], Bitmask 0b00000111, shall be all 0 on TX and ignored on RX
o Status_LKs [uint8] (Two bits each represent the Status of one LK.)
▪ Bitmask:
•
0b1100 0000: Slot 0, RX
•
0b0011 0000: Slot 0, TX
•
0b0000 1100: Slot 1, RX
•
0b0000 0011: Slot 1, TX
▪ Values (identical for all positions, see 6.4.1.8):
•
0b00: Empty
•
0b01: Ready
•
0b11: Active
•
0b10: Deactivated
o TX_IV_Counter_Slot_0 [uint64]–the current Next Link Layer TX AEAD Invocation
Counter (Slot 0).
o TX_IV_Counter_Slot_1 [uint64]–the current Next Link Layer TX AEAD Invocation
Counter (Slot 1).
The device shall check, if the BK was already written and abort with an error (0x42: Binding Key not
written yet), if this is NOT the case.
The device shall generate the IV based on the construction rules in section 6.4.1.4.
The device shall generate the ICV based on the construction rules in section 6.4.1.6.
Informative: Any of the primitive IDs 0x13, 0x21, 0x23 or 0x31 has to be called first to transport the
current PCC to the device, before using primitive ID 0x07.

UUID | No No The UUID of the target device.
Nonce | No No A Nonce chosen by the sender.
