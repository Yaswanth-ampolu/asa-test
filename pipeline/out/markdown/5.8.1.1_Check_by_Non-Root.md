# 5.8.1.1 Check by Non-Root

5.8.1.1 Check by Non-Root
The check by a non-root node for an LSconfirm of Light Sleep has several mandatory conditions,
which need to be met:
- PTB is locked
- SleepCycles*phSGx_TIME - (RestartCycles1G_a*ph1G_TIME +
RestartCyclesSGx_a*phSGx_TIME) > 25,000 … estimation of own sleep time before restart
has to be larger than 100µs
- PTBbedtime–PTBclk > 12,500 … announced time to go to sleep has to be at least 50µs into
the future
- PTB drift during SleepCycles*phSGx_TIME - (RestartCycles1G_a*ph1G_TIME +
RestartCyclesSGx_a*phSGx_TIME) is less than 140 PTB tics
If any of these conditions is not met, Light Sleep shall be denied.
Light Sleep is allowed to be denied any time.
