# 4.4.1.3 S11 Termination Test

4.4.1.3 S11 Termination Test
For S11 testing, the transceiver shall present the normal data mode termination to the PMD interface
while the transmitter is disabled. See also 3.2.18.
This test can only be triggered through local ASA register access.
