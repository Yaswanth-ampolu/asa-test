# 4.4.1.1.3 Jitter Test

4.4.1.1.3 Jitter Test
The transmit jitter is measured at MDI. The jitter is measured when in using test fixture 2 as shown in
Figure 4-28. When in jitter test mode, the PHY shall transmit a continuous pattern of 16× S {+1}
symbols followed by 16 × S {–1} symbols with the transmitted symbols timed from its local clock
source to have the square wave pattern (‘01’) for all speed grades. SeeTable 4-22 for the definition
of S.

The peak-to-peak value of the MDI output jitter relative to an un-jittered reference is measured. The
band-pass bandwidth of the measurement device shall be larger than 200MHz. The un-jittered
reference is a constant clock frequency extracted from each record of captured differential output on
MDI. The un-jittered reference is based on linear regression of frequency and phase that produces
minimum Time Interval Error. TX Jitter shall be measured over an interval of 1.26us ± 10%, and be
measured 50 times, in none of these time records, the phase drift is allowed to exceed a peak-to-
peak jitter specified in 4.4.2.
The pattern is run for 100 ms, when triggered via startup.
