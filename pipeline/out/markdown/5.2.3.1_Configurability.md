# 5.2.3.1 Configurability

5.2.3.1 Configurability
The data object for the mapper operation are all accessible through the register map:
Counter (see 3.3.8)
CounterMin (see 3.3.9)
CounterMax (see 3.3.10)
LineMin (see 3.3.11)
LineMax (see 3.3.12)
MapperTable (see 3.3.13)
The length of the Mapper cycle is “CounterMax-CounterMin+1”.
The MapperTable determines the sequence of DLP_TX_ID in the Mapper Cycle. LineMin and LineMax
function as indexing pointers into the MapperTable to select a consecutive block of lines to evaluate.
