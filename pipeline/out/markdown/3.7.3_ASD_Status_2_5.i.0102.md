# 3.7.3 ASD Status 2 (5.i.0102)

3.7.3 ASD Status 2 (5.i.0102)
This register applies to all ASEPs, which employ a packet counter.
The following ASEPs are exempt:
- Video Data
- Layer 2 Ethernet Frame
- VESA eDP
Bit(s) Name | Description | R/W* Access** Privilege***
15:8 duplicate | Saturating counter in ASD to SC O | RID
packet | track duplicate ASEP packets
7:0 missing packet Saturating counter in ASD to SC O | RID
track missing ASEP packets
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
