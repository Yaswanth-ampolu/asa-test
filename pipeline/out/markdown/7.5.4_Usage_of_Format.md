# 7.5.4 Usage of Format

7.5.4 Usage of Format
This subsection 7.5.4 is INFORMATIVE.
Byte mode is emulating bidirectional I2C mode on a byte-per-byte/bit basis. I2C condition bits are
transmitted.
Bulk mode is accumulating I2C commands of the same kind. I2C condition bits are implied.
I2C is bidirectional and accordingly, both ASE and ASD have one DLP_TX connection and DLP_RX
connection.
I2C Slave address 000_1000 is recommended to be assigned to the root node I2C Slave (connected to
ASE) for communication with that ASA node.
I2C Slave address 000_1001 is recommended to be assigned to the non-root I2C multi-mode
Master/Slave (connected to ASD) for communication with that ASA node.
