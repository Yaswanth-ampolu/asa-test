# 4.2.7.2 Startup PhaseSGA

4.2.7.2 Startup PhaseSGA
A startup PhaseSGA burst txSGA_Up or txSGA_Dn is a concatenation of a single resynchronization
header as defined in 4.2.2.3 and physical layer blocks as defined in 4.2.2.4 as in normal mode TDD
(4.2.2.2) with two differences: firstly, the input data to the physical layer block coding d_plp_tx<7:0>
is equal to zero except for the last physical layer block in each burst (see below). Secondly, the
number of containers per burst in Table 4-2 and Table 4-3 are replaced by:
Dn Speed Grade
Number of physical layer blocks
Number of baud rate symbols in
quiet gap
Table 4-16: Downstream in PhaseSGA: physical layer blocks per burst and quiet gap
The first bit being sent of the resynchronization header is its LSB. The first bit being sent of the
physical layer block tx_BlockSGA_Dn12/Dn345/Up (except the last one) is its MSB. The first bit being
sent of the last physical layer block is its LSB.
