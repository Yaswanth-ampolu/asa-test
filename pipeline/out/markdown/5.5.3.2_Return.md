# 5.5.3.2 Return

5.5.3.2 Return
The Address format for bytes n+1 to n+3 is shared with the Read command 5.5.3.1.
Byte Bit(s) Name | Description
n+4 7:0 | RegisterValue[15:8]
Read out register value from specified address.
n+5 7:0 | RegisterValue[7:0]
