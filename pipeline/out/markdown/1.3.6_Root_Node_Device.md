# 1.3.6 Root Node/Device

1.3.6 Root Node/Device
The Root node/device is the device containing the ASA node, which is in control by running OAM
sessions with all other ASA nodes in the SerDes Branch. There is only a single root node in each
SerDes Branch (designated by nodeID=1).
