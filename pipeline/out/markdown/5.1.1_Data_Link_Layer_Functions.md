# 5.1.1 Data Link Layer Functions

5.1.1 Data Link Layer Functions
The Data Link Layer provides the means to transport fixed size Data Link Layer Containers from one
node to one or more nodes in the SerDes Branch.
The payload of any Data Link Layer Container is provided to the Data Link Layer at the DLP_TX and is
delivered to OAM/ASD/FoFa at the DLP_RX.
The Data Link Layer is handling the Multiplexing of Data Link Layer Containers onto the PLP_TX and
the Demultiplexing from the PLP_RX onto the appropriate DLP_RXs. Demultiplexing includes
Duplication of multicast containers, when applicable.
The Multiplexing includes a Scheduling (deterministic time slot mapping) functionality.
