# 4.2.2.3.1 Header Assembly and Mapping

4.2.2.3.1 Header Assembly and Mapping
The physical layer resynchronization header is a vector tx_phy_rsync_hdr<0:resylen-1>, where
resylen is
Speed Grade
Number of symbols in resync header
Table 4-5: Length of resynchronization header
The prbs values of tx_phy_rsync_hdr are taken from the LFSR defined in 4.2.2.3.3, where for each bit
in tx_phy_rsync_hdr, the LFSR is advanced by one bit and rsync_prbs<i> = Sstarting with
rsync_prbs<0> until rsync_prbs<resylen-1>.
Synchronization sequences as defined in 4.2.2.3.2 are replacing parts of tx_phy_rsync_hdr starting at
positions n and m depending on Speed Grade as shown in the table below

A new value for offset is obtained for each resynchronization header from the source described in
4.2.2.3.4.
The following equation illustrates the construction of the resynchronization header for SG1 and SG2
(Downstream and Upstream):
tx_phy_rsync_hdr <k> =
rsync_prbs<k> | … 0 ≤k≤n-1
sy_double<k mod n> | … n ≤k≤n+79
rsync_prbs<k> | … n+80 ≤k≤m-1
sy<k mod m> | … m ≤k≤m+39
rsync_prbs<k> | … m+40 ≤k≤resylen-33
m_ptb<k mod (resylen-32)> | … resylen-32≤k≤resylen-17
~m_ptb<k mod (resylen-16)> | … resylen-16≤k≤resylen-1
Equation 4-1: Resync header sequence construction for SG1/2
The following equation illustrates the construction of the resynchronization header for SG3, SG4 and
SG5:
tx_phy_rsync_hdr <k> =
rsync_prbs<k> | … 0 ≤k≤n-1
sy_double<k mod n> | … n ≤k≤n+79
sy_double<k mod (n+80)> | …n+80≤k≤n+159
rsync_prbs<k> | … n+160≤k≤m-1
sy<k mod m> | … m≤k≤m+39
sy<k mod (m+40)> | … m+40 ≤k≤m+79
rsync_prbs<k> | … m+80≤k≤resylen-33
m_ptb<k mod (resylen-32)> | … resylen-32≤k≤resylen-17
~m_ptb<k mod (resylen-16)> | …resylen-16≤k≤resylen-1
