# 5.5.4.2 Self-Announce

5.5.4.2 Self-Announce
5.5.4.2.1 Generation
This is the reply to a received Node-Discover (see 5.5.4.1).
The HeaderType is set to 1, the targetID0 for the container of this OAM frame is set to 1, all other
targetIDs are set to 0.
CADnext is set to 1, OAMerror is set to 0 (see Table 5-2).
The reception of a Node-Discover not matching specification leads to a Self-announce with:
OAMerror is set to 0x3.
OAMframeID is started with 0, but incremented for every OAM frame with targetID=1.
The OAM frame contains Return commands (see 5.5.3.2) for the following registers:
DLLconfig1 (see 3.3.2)
DLLconfig2 (see 3.3.3)
VendorID (see 3.3.4)
DeviceID (see 3.3.5)
ASEP Stream Type (see 3.5.1.2) for all supported/enabled DLPs
5.5.4.2.2 Effect of receipt
Root node reacts with further OAM messages to origin nodeID for additional configuration as
appropriate.
