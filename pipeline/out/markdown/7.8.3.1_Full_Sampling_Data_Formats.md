# 7.8.3.1 Full Sampling Data Formats

7.8.3.1 Full Sampling Data Formats
For the full sampling data format, 5 different codings, each coding is covering a range of pin count,
are defined. The coding shall fit the number of valid GPIO pin IDs, where the small capital variables
‘a’ through ‘p’ correspond to the ordered ascending set of active GPIO pin IDs.
The first sample of a packet shall always correspond to the beginning of a TDD cycle such that there
are always the same number of samples in a packet for a given GPIO pin sampling period.
