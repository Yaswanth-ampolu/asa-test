# 6.3.3.1 DeviceInternal.install_key

6.3.3.1 DeviceInternal.install_key
This primitive is highly critical to only be callable by the KeyEx.
This primitive shall setup the following state per link and key slot:
•
Link Key
•
Salt
•
Next Link Layer TX AEAD Invocation Counter = 1
Last Link Layer RX AEAD Invocation Counter = 0
