# 4.4.1.4 Phase1G Loopback Test

4.4.1.4 Phase1G Loopback Test
For this test mode, the device acts as a root node for PCS/PAM transmit and a non-root node for
PCS/PMA receive. The detection of a single Phase1G block is signaled by setting Polarity Detect in the
register defined in 3.2.12 to 0x01 and concludes the test.
This test can only be triggered through local ASA register access.
