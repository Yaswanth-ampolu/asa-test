# 4.2.8.1.1 Status

4.2.8.1.1 Status
Valid bit in each message can be used to invalidate the message to prevent the follower from using
the time stamps for any calculation.
The local clock leader shall invalidate the status, when the clock follower in the same device is not
locked (status of clock follower is 0).
