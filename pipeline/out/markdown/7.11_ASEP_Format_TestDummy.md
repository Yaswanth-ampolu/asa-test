# 7.11 ASEP Format: TestDummy

ASEP Format: TestDummy
This format purely serves testing purposes. It shall be supported on each implemented ASEP. When
ASEP Test mode is enabled (see section 3.5.1.4), the sequence of up to four packets is sent
repeatedly (see section 3.6.4) by the ASE. Any ASD in TestDummy mode shall be able to receive ASEP
packets in this section and check correctness of packets.
