# 3.6.3 ASE Test (4.i.0102)

3.6.3 ASE Test (4.i.0102)
This register controls the type of test mode for an ASE. The principle ASEP test mode
enabled/disabled is controlled by the register in section 3.5.1.4.
Bit(s) Name | Description | R/W* Access** Privilege***
15:4 | reserved
3:2 Test Mode | 0: TestDummy | RW L | RID
1: ASE Test
ASE Test mode sends a
sequence of all supported ASEP
packets on this ASEP
All application interface input is
replaced by dummy data.
ASA register contained ASEP
configurations are taken from
the registers.
Data and sequence derived
values are consistently updated.
Entering ASE test mode resets
all ASEP internal packet counters
and status, exiting ASE test
mode resets them again.
DLL state is unaffected by
entering and leaving ASE test
mode
2-3: reserved
reserved
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
