6.4.3.14KeyEx.report_status_LK (ID: 0x81)
This primitive allows an ASA Node to report the status of LK to the Root Node, see section 6.3.4.2.
The ID of this primitive shall be 0x81.
This function shall be executable multiple times.
The IV and ICV shall only be present, if the Status is OK (0x00).
The device shall generate the IV based on the construction rules in section 6.4.1.4 using the installed
salt.
The message shall transport the Status_LKs_IVs struct of section 6.4.3.5.
The device shall generate the ICV based on the construction rules in section 6.4.1.6.
The request shall contain the following parameters:
Parameter | Length (bits) Enc. Auth. Description
IV | n/a n/a See section 6.4.1.4
UUID | No Yes The UUID of the target device (=Root
Device).
Status_LKs_IVs N | No Yes Status_LKs_IVs struct as defined in
section 6.4.3.5.

•
Key: BK
•
IV: see above
•

o ID (= 0x81)
o UUID
o Nonce
source.
