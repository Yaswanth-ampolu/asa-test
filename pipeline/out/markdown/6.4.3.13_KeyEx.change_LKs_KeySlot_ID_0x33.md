6.4.3.13KeyEx.change_LKs_KeySlot (ID: 0x33)
This primitive is used to change the active Key Slot for Link Keys on an ASA Device.
The ID of this primitive shall be 0x33.
This function shall be executable multiple times.
The IV and ICV shall only be present, if the Status is OK (0x00).
The device shall check, if the DK_0 was already written and abort with an error (0x40: Device Key
Part 0 missing), if this is NOT the case.
The device shall check, if the DK_1 was already written and abort with an error (0x41: Device Key
Part 1 missing.), if this is NOT the case.
The device shall check, if the BK was already written and abort with an error (0x42: Binding Key
missing), if this is NOT the case.
The device shall generate the IV based on the construction rules in section 6.4.1.4 using the freshly
installed salt.
The device shall generate the ICV based on the construction rules in section 6.4.1.6.
The field KeySlot has the following format:
•
NodeID-KeySlot-Combination (1 byte)
o NodeID [7…3], Bitmask 0b11111000
o Reserved [2…1], Bitmask 0b00000110, shall be all 0 on TX and ignored on RX
o KeySlot [0], Bitmask 0b00000001
