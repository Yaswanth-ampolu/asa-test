# 6.4.3.3 KeyEx.read_current_nonce (ID: 0x04)

6.4.3.3 KeyEx.read_current_nonce (ID: 0x04)
Thisprimitive is used to read the device’s Power Cycle Nonce (PCN) valid in the current power cycle,
which was generated by the device at the beginning of the power cycle.
The ID of this primitive shall be 0x04.
This function shall be executable multiple times.
The request shall contain the following parameters:
Parameter | Length (bits) Enc. Auth. Description
Table 6-9: Request (ID 0x04)
The response shall contain the following parameters:
Parameter | Length (bits) Enc. Auth. Description
Status | No No See section 6.4.1.3.
Relevant codes: 0x00, 0x10, 0x30, 0xFF
PCN | No No Power Cycle Nonce: The nonce chosen by
this device, which is valid for the current
power cycle.
