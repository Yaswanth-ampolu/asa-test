# 3.5.4.2 I2C slave addresses (4/5.i.0201-4/5.i.0208)

3.5.4.2 I2C slave addresses (4/5.i.0201-4/5.i.0208)
The I2C slave addresses are distributed over 8 registers, one per two addresses. Each register has the
format as shown in Table 3-89.
Bit(s) Name | Description | R/W* Access** Privilege***
Offset | Flag for offset address length | RW O | RID
address | 1: 16bit offset address
length flag N 0: 8bit offset address
14:8 Slave | 7 bit slave address | RW O | RID
address N 1111 000 when unused****
Offset | Flag for offset address length | RW O | RID
address | 1: 16bit offset address
length flag M 0: 8bit offset address
6:0 Slave | 7 bit slave address | RW O | RID
address M 1111 000 when unused****
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
**** This is not in conflict with I²C bus specification as 10-bit addressing is not supported by this ASEP
