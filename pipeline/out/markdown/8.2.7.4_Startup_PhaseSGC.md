# 8.2.7.4 Startup PhaseSGC

8.2.7.4 Startup PhaseSGC
A startup PhaseSGC burst txSGC_Up or txSGC_Dn is a concatenation of a single resynchronization
header as defined in 4.2.2.3 and physical layer blocks as defined defined in 8.2.2.4 as in normal mode
TDD (8.2.2.2) with one difference: the input data to the physical layer is equal to all zeros except for
the last physical layer block in each burst (see below).
The first bit being sent of the resynchronization header is its LSB. The first bit being sent of the
physical layer block (except the last one) is its MSB. The first bit being sent of the last physical layer
block is its LSB.
The number of symbols in the quiet gap is the same as in normal mode (see Table 8-3).
The last physical layer block is identical to PhaseSGA as defined in Equation 8-1.
The PCS Scrambler is being run as described in 8.2.2.5.1 for all MLE modes.
For MLE modes derived of Speed Grades 4 and 5, scrambled physical layer block symbols and
symbols of Equation 8-1 are mapped to PAM4 as in normal mode (4.2.2.7), scrambled symbols of all
MLE modes derived of Speed Grades 1,2 and 3 are mapped to PAM2 as in normal mode (4.2.2.6).
