# 7.3.2 Common ASEP Format Basics per Header

7.3.2 Common ASEP Format Basics per Header
All ASEP headers start with the following fields:
Byte Bit(s) Name | Description
7:1 | ASEP stream type | See Table 7-1: ASEP stream types
Same container ASEP 0: there is no further ASEP header in the same
header follow flag | container; if the length of the ASEP packet is
shorter than the container, it is filled with dummy
data
1: there is another ASEP header in the same
container directly after the last byte of the
current packet
Table 7-4: Common ASEP header format–first byte
The PTB time stamp for ASEPs is described in 7.3.2.1.
Further information including ASEP packet length is defined in the stream type specific portion of the
header definition.
