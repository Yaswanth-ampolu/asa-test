# 6.4.4.3 Device Key OEM and Binding Key Installation (encrypted)

6.4.4.3 Device Key OEM and Binding Key Installation (encrypted)
The following process shall be run to securely install the DK_1 and BK (e.g. in an untrusted
environment) for 1 or more devices:
•
For each device:
o Read out the UUID using KeyEx.read_UUID
o Read out the Key Status using KeyEx.read_status_keys
•
Based on the information read out, acquire the encrypted payloads for installing via
KeyEx.install_DK_1_encrypted and KeyEx.install_BK_encrypted
•
For each device:
o Install DK_1 using KeyEx.install_DK_1_encrypted
o Install BK using KeyEx.install_BK_encrypted
o Collect returned proofs and status
o Read out the Key Status using KeyEx.read_status_keys
•
Evaluate proofs and key status.
