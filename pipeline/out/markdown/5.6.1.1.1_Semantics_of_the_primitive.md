# 5.6.1.1.1 Semantics of the primitive

5.6.1.1.1 Semantics of the primitive
DLP_TX.indicateSlot(size)
The DLL uses indicateSlot to request from the ASE or OAM respectively a data unit of size to transmit.
The size parameter can take one of the following values:
Dn_P2P | Downstream for point to point stream (638 bytes)
Dn_P2P_Sec | Downstream for point to point stream, secured (620 bytes)
Dn_MC | Downstream for multicast stream (636 bytes)
Dn_MC_Sec | Downstream for multicast stream, secured (618 bytes)
Up_P2P | Upstream for point to point stream (208 bytes)
Up_P2P_Sec | Upstream for point to point stream, secured (190 bytes)
Up_MC | Upstream for multicast stream (206 bytes)
Up_MC_Sec | Upstream for multicast stream, secured (188 bytes)
OAM_frame | Downstream and Upstream, any configuration (188 bytes)
