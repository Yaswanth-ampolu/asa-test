6.4.3.10KeyEx.install_BK_encrypted (ID: 0x21)
This primitive is used to install the Binding Key persistently.
The ID of this primitive shall be 0x21.
This function shall be executable multiple times.
The request shall contain the following parameters:
Parameter | Length (bits) Enc. Auth. Description
IV | n/a n/a See section 6.4.1.4
Nonce | No Yes A Nonce chosen by the sender.
source
Informational: Used for Response Replay
Protection
UUID | No Yes The UUID of the target device.
Key_Length | No Yes Key Length in Bytes (e.g.: AES-128: 16,
AES-256: 32)
BK | – | Yes Yes Encrypted: The BK to be stored.
