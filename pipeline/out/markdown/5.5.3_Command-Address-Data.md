# 5.5.3 Command-Address-Data

5.5.3 Command-Address-Data
Every CAD structure starts with the Command byte:
Byte Bit(s) Name | Description
n | CADnext | 1: further CAD present after this CAD, 0: no
further CAD present
n | 6:0 | Command | Contains a command code as listed in Table 5-4
Table 5-3: CAD first byte
The additional fields Address and Data are defined per command below. Addresses refer to ASA
register addresses (see 3). Data refers to any parameters/values passed on with the command.
The commands are coded with 7 bits:
Code OAM command | Code OAM command
reserved | Read | 5.5.3.1
Return | 5.5.3.2 | ReadError | 5.5.3.3
Write | 5.5.3.4 | WriteAck | 5.5.3.5
StartEnum | 5.5.3.6 | LongAtom | 5.5.3.7
LongAtomClose | 5.5.3.8 | StartTDD | 5.5.3.9
LSannounce | 5.5.3.10 | LSconfirm | 5.5.3.11
LSdeny | 5.5.3.12 | LSsleep | 5.5.3.13
…
KeyExMsg Request 5.5.3.14 | KeyExMsg Response 5.5.3.14
Table 5-4: OAM commands (part1)

shown in Table 5-5.
