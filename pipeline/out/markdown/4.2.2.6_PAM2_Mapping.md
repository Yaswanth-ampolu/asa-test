# 4.2.2.6 PAM2 Mapping

4.2.2.6 PAM2 Mapping
The PCS transmit function shall map consecutive bits of tx_phy_block_scr to consecutive PAM2
symbols starting with the MSB of tx_phy_block_scr.
Each bit of tx_phy_block_scr is mapped to one PAM2 symbol M(j) as follows:
0 maps to 1,
1 maps to -1.
