# 3.4.3 droppedContainersSecTX (3.0003)

3.4.3 droppedContainersSecTX (3.0003)
Every ASA Node shall have a register for determining the number of filtered / rejected containers on
the TX path.
Bit(s) Name | Description | R/W* Access** Privilege***
15:0 droppedContainersSecTX Number of dropped / | SC O | RID
rejected Containers,
Saturating
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
Table 3-73: DroppedContainersSecTX Register
ASEP Registers
ASEP Registers use a subdomain identifier “i" after the domain toidentify the ASE or ASD (see also
section 3).
Registers in the address range 4/5.i.0001-0099 are defined for all ASEPs.
Registers in the address range 4/5.i.0051-0099 are for each address the same register for all
subdomains.
Registers in the address range 4.i.0100-0199 are defined for all ASE (regardless of protocol or serve a
generic function).
Registers in the address range 5.i.0100-0199 are defined for all ASD (regardless of protocol or serve a
generic function).
Registers starting from address 4/5.i.0200 and higher are specific to each ASEP and semantics change
based on streamType (see section 3.5.1.2).
