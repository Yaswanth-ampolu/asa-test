# 1.3.1 ASA Node

1.3.1 ASA Node
An ASA node is a stack of a single Physical Layer, a single Data Link Layer and one or more Application
Stream Encapsulators/Decapsulators. In the case of optional Link Aggregation, the single Physical
Layer is replaced by the Link Aggregation Sublayer and a multitude of Physical Layers.
