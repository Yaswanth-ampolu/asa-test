# 5.3.2.1 Local Sink

5.3.2.1 Local Sink
Condition: | targetIDx==NodeID (see 3.3.1) && targetIDx!=0
Action: | for all DLP_RX_ID in DemuxTable1 (see 3.3.15), that match nodeID.streamID of
the header, execute primitive 5.7.1.1
Check packetID in received header versus fullPacketID[4:0]+1 in 3.5.1.1:
if they match, increment fullPacketID in 3.5.1.1,
if received packetID is too low, signal duplicate_packetID in primitive 5.7.1.1 and
increment 2.2210.7:0 (see 3.3.25),
if received packetID is too high, signal missing_packetID in primitive 5.7.1.1 and
increment 2.2211.15:8 (see 3.3.26)
Error Handling: if nodeID.streamID is not found in 3.3.15, increment 2.2147.15:8 (see 3.3.17) and
discard container
