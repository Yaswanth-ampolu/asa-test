# 7.7.6 SPI Interrupt Packet

7.7.6 SPI Interrupt Packet
If the connected SPI devices support the interrupt feature, this packet is used to convey the
information.
The ASA node connected to the interrupting SPI slave should implement a watchdog and repeat the
interrupt message after a timeout (value depending on schedule cycle and application use case).
Byte Bit(s) Name | Description
m +2 7:6 | Reserved
HB
m +2 5:2 | Interrupt Source | Chip Select value
HB
0: ASA node (interfacing to SPI slave) itself
1..15: external SPI slave Chip Select value
For an interrupt packet, this field identifies the
source of the interrupt.
m +2 1:0 | Reserved, set to 0
HB
m +3 7:0 | Interrupt counter [7:0] Unsigned integer
HB
Increments for each assertion and deassertion
of an interrupt, starts at 1, roles over from 127
to 1
Shared counter for all interrupt sources
0: reserved
m +4 | SPI slave interrupt flag 0: no interrupt
HB
1: interrupt active
This function is for eSPI device. If Slave wants to
start SPI transaction, Slave can inform Master by
using this interrupt flag. If ASA device receives
this interrupt flag from SPI Slave, then ASA
device issues the this SPI ASE packet which
contains interrupt flag
m +4 | Reserved
HB
m +4 4:2 | Operation status SPI 0x0: Normal status.
HB
slave side [2:0] | 0x1: Busy (ASD buffer is not empty)
