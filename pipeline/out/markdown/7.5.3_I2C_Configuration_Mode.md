# 7.5.3 I2C Configuration Mode

7.5.3 I2C Configuration Mode
For configuration mode, the I2C Master side ASA node shall send the contents of relevant ASA
registers once after startup and once after each register write access. The I2C slave side ASA node
shall update its registers with the content of the ASEP packet.
