# 5.5.3.1 Read

5.5.3.1 Read
Byte Bit(s) Name | Description
n+1 7:5 | AddressDomain | unsigned integer, see Table 3-2: ASA register
domains
n+1 4:0 | DLP_ID[5:1]
Identifies the DLP for ASE/ASD, ignored, if
AddressDomain is not 4 or 5
n+2 | DLP_ID[0]
n+2 6:0 | Address[14:8]
Address to be read from in the specified
AddressDomain
n+3 7:0 | Address[7:0]
Table 5-6: Read Command Address
AddressDomain identical to “d” in. DLP_ID is identical to “i” in. Address is identical to “a” in3.
The Read command does not have a data field.
Result of the read command is returned with the Return command, see 5.5.3.2. If an error occurred,
the ReadError (see 5.5.3.3) is used to reply instead.
