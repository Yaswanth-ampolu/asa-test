# 6.4.2.1 Key Exchange Requests

6.4.2.1 Key Exchange Requests
Informational: Key Exchange Requests use the OAM Command 0x7D which is reserved for Security.
For requests the OAM structure mapping shall be like this (Bytes counted after the OAM Header):
Byte | Bit(s) | Value | Description
CADnext
6:0 | 0x7C | Command
7:0 | ID | Primitive ID
7:0 | 0x00 | Reserved
3 … n | 7:0 | Parameters | Primitive Parameters
