# 7.5.2.1 Command Mode

7.5.2.1 Command Mode
In I2C bulk mode, the lower bits of the command byte are defined as shown in Table 7-17.
Byte Bit(s) Name | Description
m +2 | Reserved
HB
m +2 | I2C Address Mode | 0: Random location (Offset Address Set)
HB
1: Current location (Offset Address not Set)
m +2 2:0 | I2C Format Type | 000: Write command format
HB
001: Read command format
010: Ack/Nack format
011: Read response format
1xx: Reserved
Table 7-17: ASEP I2C–Bulk mode command format
