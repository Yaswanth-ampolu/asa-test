# 6.4.3 Primitives of the Key Exchange Entity (KeyEx)

6.4.3 Primitives of the Key Exchange Entity (KeyEx)
Primitives with an even ID (least significant bit = 0) shall be used for unprotected/unencrypted
operations.
For all KeyEx primitives the AEAD is based on the layout of the OAM message for this primitive.
Primitive parameter fields are mapped to OAM Messages in the order, in which they are given, each
field is mapped with its MSByte first.
