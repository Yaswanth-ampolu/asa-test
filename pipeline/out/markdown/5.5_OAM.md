# 5.5 OAM

OAM
Operation, Administration, Management is an ASA internal communication channel between the
root node and the non-root nodes in Branch and Leaf Devices. The root node runs an OAM session
with each non-root node whereas each non-root node only runs a single OAM session with the root
node.
OAM is used to configure and control ASA nodes and to obtain status and diagnostics/debug
information of ASA nodes, both through OAM CAD (Command-Address-Data) for access of the ASA
register map and complementing special instructions.
LongAtom is a special OAM mechanism, in which a marked block of CAD operations spanning more
than one OAM frame are buffered at the receiving side and only executed, when the LongAtomClose
is received.
If Security is present, OAM is also used to facilitate communication with the Key Exchange Entity.
