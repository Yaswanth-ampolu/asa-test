# 4.3.3.1 Startup State Diagrams

4.3.3.1 Startup State Diagrams
Every ASA node goes through startup Phase1G, PhaseSGA and PhaseSGB. Speed Grades 4 and 5 also
go through startup PhaseSGC. This section contains state diagrams and relevant constants, variables,
timers, counters, functions and messages for the states diagrams.
The patterns for the startup are defined in 4.2.7.
In this entire section 4.3.3.1: when the term root node (leaf node) is used, it is also applicable to any
far-side (near-side) node in an ASA SerDes Branch.
Each node during startup shall not start transmission of a startup burst while a startup burst from the
other side is still being received.
