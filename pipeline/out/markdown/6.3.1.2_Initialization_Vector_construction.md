# 6.3.1.2 Initialization Vector construction

6.3.1.2 Initialization Vector construction
For a given key, the Initialization Vector (IV) for the AEAD algorithm needs to be unique for every
packet protected with it.
The Length of the IV for Link Layer Security based on AES-GCM or AES-GMAC shall be 96 bits.
The IV for Link Layer Security shall consist of a fixed field (32 bit) and an invocation field (64 bit).
Construction:
Part | Field | Length (bit)
KeyEx = 0
Fixed Field (32 bit) | Dir
Salt
Invocation Field (64 bit) | Link Layer TX AEAD Invocation Counter
Table 6-1: Link Layer Security IV Construction
The fields shall be defined as follows:
•
KeyEx: Shall be 0 since the IV belongs to a secured Link Layer Container and not a Key
Exchange message.
•
Dir: Shall be 0 if the secured Link Layer Container is a Downstream Container and 1 if the
secured Link Layer Container is an Upstream Container.
•
Salt: Shall be set by the Link Key Installation (see 6.4.3.12)
“NextLink Layer TX AEAD Invocation Counter”: Counter that increments for every AEAD invocation in
TX direction for secured Link Layer Containers only and starts with 1.
