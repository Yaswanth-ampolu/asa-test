# 4.7.1.2 PLP_RX.linkLoss

4.7.1.2 PLP_RX.linkLoss
4.7.1.2.1 Semantics of the primitive
PLP_RX.linkLoss(index)
The PhyL uses PLP_RX.linkLoss to indicate, that an expected TDD burst could not be detected.
The parameter index indicates the Lane in the case of Link Aggregation (see section 4.8) and defaults
to 0 in the case of no Link Aggregation.
