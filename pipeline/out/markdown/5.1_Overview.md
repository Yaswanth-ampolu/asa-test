Figure 5-1: Data Link Layer with interfaces to OAM entity and Security entity
The Data Link Layer interfaces to the Physical Layer via PLP_TX and PLP_RX, and interfaces to the
Application Stream Encapsulator/Decapsulator via DLP_TX and DLP_RX.
It contains two functional sub-blocks: the OAM entity and Security entity. The OAM entity uses the
interfaces DLP_TX and DLP_RX as well. The Security entity defines its own interfaces.
There is only a single PLP_TX and single PLP_RX connected to a Data Link Layer. There are up to 64
DLP_TX and up to 64 DLP_RX connected to a DLL, which are identified by their respective DLP_TX_ID
and DLP_RX_ID. OAM is by definition connected to DLP_TX_ID=0 and DLP_RX_ID=0.
