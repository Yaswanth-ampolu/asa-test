# 7.7.3 SPI Packet Header

7.7.3 SPI Packet Header
The SPI ASEP header format is shared for all packet modes. SPI packet IDs are a single sequence of
IDs over all packet modes.
Byte Bit(s) Name | Description
m +1 | SPI packet mode | 0: SPI configuration mode
HB
1: SPI data mode
m +1 6:0 | SPI packet ID | The SPI packet ID starts at 1 and increments by 1
HB
up to 120, and rolls over to 1
0, 121-126 are reserved values
ASE interfacing to SPI master assigns each new
SPI packet this incrementing SPI packet ID
ASE interfacing to the SPI slave sets the SPI
packet ID to mark the response to a received SPI
packet
A value of 127 in this field signifies an SPI
interrupt, it does not affect any packet ID
counters
