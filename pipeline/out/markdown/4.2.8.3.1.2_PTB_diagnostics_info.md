# 4.2.8.3.1.2 PTB diagnostics info

4.2.8.3.1.2 PTB diagnostics info
If the local PTB is locked, the time stamp in the OAM header is used to calculate the PTBoamDly (see
3.3.22). Whenever the local PTBclock is not locked, the value PTBoamDly must be set to 0.
