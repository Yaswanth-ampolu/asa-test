# 5.8.1 Entering Light Sleep

5.8.1 Entering Light Sleep
Light Sleep is negotiated via exchange of special OAM CADs described in 5.5, whereas state diagrams
are described in 5.8.3.
Light Sleep is announced by either root or a non-root node, but always executed by the root node.
The non-initiating node must deny Light Sleep under certain conditions and always can deny Light
Sleep; no node can be forced into Light Sleep.
It is the responsibility of the root node to mediate the decision to go into Light Sleep including its
parameters of time to sleep and restart time.
This means to announce Light Sleep to all non-initiating nodes, which are affected, either by being on
the same link of the announcing node or by being on a part of the ASA SerDes Branch that is
connected to the root node by the link that wants to go to Light Sleep. Light Sleep shall not isolate a
node in normal mode from the root node.
This also means to determine from all announced or confirmed parameters, whether Light Sleep is
feasible, i.e. a controlled time to enter Light Sleep as well as enough time to restart from sleeping is
available for all affected nodes.
If either of these conditions cannot be met, the root node shall deny Light Sleep.
