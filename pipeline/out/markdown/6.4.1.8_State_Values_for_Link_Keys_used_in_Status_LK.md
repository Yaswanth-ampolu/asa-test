# 6.4.1.8 State Values for Link Keys (used in Status_LK)

6.4.1.8 State Values for Link Keys (used in Status_LK)
The Link Key States used in Status_LK shall be defined as follows:
•
0b00: Empty–No key installed
•
0b01: Ready–Key installed but not active yet
•
0b11: Active–Key installed and in usage
•
0b10: Deactivated–Key installed but deactivated (for RX: received valid switch to different
slot, for TX: other slot got activated by KeyEx OAM message).
