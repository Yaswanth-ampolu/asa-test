# 7.7.2.2 SPI Slave Function and ASA Device Interfacing to SPI Slave

7.7.2.2 SPI Slave Function and ASA Device Interfacing to SPI Slave
The SPI master on the ASD of ASA device (branch or leaf) connected to the SPI slave is able to stop
issuing the SCK to pause the SPI communication when the ASD receives an empty SPI packet from
ASA node interfacing to the SPI master (root).
The SPI slave side clock rate SCK satisfies the condition: S_SCK*SPI_STC ≥ 128bytes, i.e. the
maximum payload sent in one container can locally be turned around on the SPI within SPI_STC. The
MOSI buffer at the SPI slave side is never fuller than 128 bytes and the latency of the turnaround to
gather the response data is SPI_STC at maximum.
