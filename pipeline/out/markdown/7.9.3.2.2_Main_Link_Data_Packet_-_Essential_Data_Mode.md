# 7.9.3.2.2 Main Link Data Packet - Essential Data Mode

7.9.3.2.2 Main Link Data Packet - Essential Data Mode
The Main Link Data packet encapsulates pixel data, secondary data packets and stuffed data (in case
of HDCP). Either the 1-, 2- or 4-lane mapping of DP can be encapsulated, the four available Komma
slots at the start and the end allow compatibility with the Enhanced Framing Mode. When a series of
Transfer Units is encapsulated into a Main Link Data Packet, it shall be broken at a Komma Symbol. It
may also be broken arbitrarily, where all four Komma Symbols are set to “No Komma” (see below).
