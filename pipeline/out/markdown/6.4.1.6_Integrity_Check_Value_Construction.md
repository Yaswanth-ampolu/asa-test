# 6.4.1.6 Integrity Check Value Construction

6.4.1.6 Integrity Check Value Construction
Informational: Secured Key Exchange Primitives require the use of an Integrity Check Value (ICV).
The ICV shall be constructed from the fields defined in the respective primitive using Network Byte
Order (Big Endian), where the order of fields is identical to the order in the primitive definition.
