# 7.8.2.5 Mode 1 ACK/NACK Command

7.8.2.5 Mode 1 ACK/NACK Command
The payload of the Mode 1 ACK/NACK command is identical to the Mode 1 Write command payload
(see section 7.8.2.2) except for the field below.
Byte | Bit(s) Name | Description
m +2 | ACK/NACK | 0: write failed
HB
1: write succeeded
Table 7-46: ASEP GPIO–Configuration mode 1 ACK/NACK command format
The root node should implement a timeout watchdog (depending on the schedule cycle for this ASEP
and the application use case) and treat a timeout as a NACK (all zeros).
