# 8.6.2.4 CRC8 Definition

8.6.2.4 CRC8 Definition
The cyclic redundancy check shall use the polynomial 0xA6.
The starting value of the CRC is 0xFF.
The appendix (XOR value) of the CRC is 0xFF.
The input data shall be used byte-wise reflected.
The result data shall be used reflected.
