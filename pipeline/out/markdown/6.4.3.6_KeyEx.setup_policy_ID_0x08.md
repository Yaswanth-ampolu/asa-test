# 6.4.3.6 KeyEx.setup_policy (ID: 0x08)

6.4.3.6 KeyEx.setup_policy (ID: 0x08)
This primitive is used to set the policy for one or more nodes.
This primitive includes the Node_Policies struct:
•
Number of Entries [uint8]
•
Array of Policies:
o Node [uint8]
▪ NodeID [7…3], Bitmask 0b11111000
▪ Reserved [2…0], Bitmask 0b00000111, shall be all 0 on TX and ignored on RX
o Policy [uint8]:
▪ 0: No Security
▪ 1: Authentication only
▪ 3: Authentication and Encryption
▪ 2, 4-255: Reserved
This primitive changes the read-only ASA Security Register defined in Section 3.4.1.
If the PCN does not fit the current PCN of the device, this command is not executed and returns
status 0xFF.
If the PCN matches, the Node Security Policies are set accordingly to the Node_Policies struct.
If the parameter Persist is set to 1, the Node Security Policies included shall be stored persistently
and it shall not be possible to change them again. (This only includes the Nodes present in the
struct).
If one of the included Node Security Policies has been persistently written before, the return code
0x20 shall be used and no policy shall be changed.
If persistently storing the Node Security Policy fails, the return code 0x21 shall be used.
All changes in Node Security Policy take effect at the beginning of the next link startup, regardless
whether it has been written persistently or non-persistently.
The request shall contain the following parameters:
Parameter | Length (bits) Enc. Auth. Description
PCN | No No Power Cycle Nonce: The nonce chosen by
this device, which is valid for the current
power cycle.
Persist | No No Whether this is written persistently:
0: Do not persist (for power cycle only).
1: Do persist (permanently, write once).
2-255: Reserved.
Node_Policies | N | No No Node_Policies Struct as defined before.
