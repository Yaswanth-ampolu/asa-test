# 6.4.3.4 KeyEx.read_status_keys (ID: 0x06)

6.4.3.4 KeyEx.read_status_keys (ID: 0x06)
This primitive is used to read the status of the keys installed on the device.
The ID of this primitive shall be 0x06.
The primitive shall include the following Status_LKs struct:
•
Number of entries [8bit]
•
Array of Status_LK:
o Node [uint8]
▪ NodeID [7…3], Bitmask 0b11111000
▪ Reserved [2…0], Bitmask 0b00000111, shall be all 0 on TX and ignored on RX
o Status_LKs [uint8] (Describes the direction based status of the two key slots with 2
bits. Keep in mind that the status of a single key can be different based on direction
during the process of changing the key slot.)
▪ Bitmask:
•
0b1100 0000: Slot 0, RX
•
0b0011 0000: Slot 0, TX
•
0b0000 1100: Slot 1, RX
•
0b0000 0011: Slot 1, TX
▪ Values (identical for all positions, see 6.6.1.8):
•
0b00: Empty
•
0b01: Ready
•
0b11: Active
•
0b10: Deactivated
This function shall be executable multiple times.
