# 3.3.6 DLLaddrtable (2.0008-2.0133)

3.3.6 DLLaddrtable (2.0008-2.0133)
The address table is distributed over 63 registers, two per DLP_TX/streamID. The first register per
streamID has the format as shown in Table 3-33.
Bit(s) Name | Description | R/W* Access** Privilege***
15:14 | Reserved
valid_targetID0 1: targetID0 set, 0: not set | RW O | RID
12:8 targetID / | targetID0 for DLP_TX=… | RW O | RID
targetID0
7:6 | Reserved
valid_targetID1 1: targetID1 set, 0: not set | RW O | RID
4:0 targetID1 | targetID1 for DLP_TX=… | RW O | RID
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
Table 3-33: first DLLaddrtable register per streamID–extended definition
The second register per DLP_TX/streamID has the format as shown in Table 3-34.
Bit(s) Name | Description | R/W* Access** Privilege***
15:14 | Reserved
valid_targetID2 1: targetID2 set, 0: not set | RW O | RID
12:8 targetID2 | targetID2 for DLP_TX=… | RW O | RID
7:6 | Reserved
valid_targetID3 1: targetID3 set, 0: not set | RW O | RID
4:0 targetID3 | targetID3 for DLP_TX=… | RW O | RID
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
Table 3-34: second DLLaddrtable register per streamID–extended definition
The DLP_TX_ID/streamID 0 is permanently assigned to OAM.
