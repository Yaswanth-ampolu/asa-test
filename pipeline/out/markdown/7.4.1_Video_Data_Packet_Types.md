7.4.1 Video Data Packet Types
All headers start with the following fields:
Byte Bit(s) Name | Description
m +1 7:5 | Video Data header | 000: Pixel Clk
HB
type | 001: Video Line, video data
010: Video Line, format specific data
011: Video Line, vendor/user specific data
100: Video Line, null data
101..111: reserved
