# 4.8.4.1 Handling of LinkID and GroupID

4.8.4.1 Handling of LinkID and GroupID
LinkID and GroupID are exchanged in the m_ptb field of Startup Phase1G, see section 4.2.7.1.
The Root node (or far-side node) defines the linkID (sending the value from register in section
3.2.19); The Leaf node (or near-side node) copies the received value into the same register.
The Leaf node replies with same LinkID for confirmation; replies with differing linkID to indicate error
(see register in section 3.2.19).
The Root node (or far-side node) sends the GroupID (equal to value in register in section 3.2.2) on all
links. The Leaf node (or near-side node) responds with the GroupID received on the lowest linkID on
all links.
The Root node checks the received GroupID values and reports the status in the register in section
3.2.4.
