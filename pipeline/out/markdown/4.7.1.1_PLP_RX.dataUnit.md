# 4.7.1.1 PLP_RX.dataUnit

4.7.1.1 PLP_RX.dataUnit
4.7.1.1.1 Semantics of the primitive
PLP_RX.dataUnit(phyL_block_rx,errStat)
The PhyL uses PLP_RX.dataUnit to provide a received physical layer block along with its RS-FEC
decoding status.
The parameter phyL_block_rx can have two sizes:
642 bytes | for Downstream
212 bytes | for Upstream
errStat can have three values:
noErr | no byte error occurred
corErr | corrected byte error(s)
uncErr | uncorrectable byte errors
4.7.1.1.2 When generated
Generated by PhyL each time RS-FEC check/decode finishes.
4.7.1.1.3 Effect of receipt
DLL executes DLL Receive Process.
