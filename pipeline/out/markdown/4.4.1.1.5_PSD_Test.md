# 4.4.1.1.5 PSD Test

4.4.1.1.5 PSD Test
PSD test is for checking whether the transmitter is compliant with the transmit PSD masks that are
defined in 4.4.2. In this test mode, the transmitter is at normal operations at the relative speed
grade, the transmit power measured into a 100 Ω load using the test fixture 2 shownin Figure 4-29.
The pattern is run for 500 ms, when triggered via startup.
