# 6.3.1.3.2 ICV

6.3.1.3.2 ICV
Length: 128 bits
Relative Position: After Container Payload
The field ICV is the Integrity Check Value of all Container fields starting with the Container Header
and ending with the Container payload.
In case of AES-GCM or AES-GMAC, the ICV is represented by the Auth Tag.
