# 4.8.1 Overview

4.8.1 Overview
The Link Aggregation Sublayer allows the aggregation of the communication over 2-4 physical layer
ports into a single physical layer port.
The Link aggregation Sublayer shall only aggregate physical layers of identical Speed Grades and
direction (Downstream or Upstream). This limitation preserves the order of physical layer blocks (and
DLL containers).
Informative: differential delay due to different propagation delay on the cable can be compensated
in the receiver. The combination of minimum and maximum channel length is allowed, see also
section 4.5).
There shall only be a single DLL instance in the presence of a Link Aggregation Sublayer.
There is only a single instance of PTBclk (see section 3.3.19 and 0). Also refer to section 4.8.3.
