Bit widths of the fields of an address are described in 5.5.3.1.
The default reset value of each register is 0, unless otherwise stated in the register definition.
Register Types and Access
ASA Registers have one of three read/write types: read/write (R/W), read-only (RO) and read-only
with automatic reset, when they are read (self-clearing = SC).
ASA Register access is either L=local only or by O=OAM (which implies local access).
ASA Register privilege through OAM access is either by root node only (RID=rootID) or only, when
access is from root node and the link is protected by security (A=authenticated).
User Registers
Register addresses with d=0 are accessible by OAM channel. Number of registers and register
contents are left to the implementer.
