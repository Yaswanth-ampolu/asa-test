# 8.2.7.3 Startup PhaseSGB

8.2.7.3 Startup PhaseSGB
A startup PhaseSGB burst txSGB_Up or txSGB_Dn is a concatenation of a single resynchronization
header as defined in 4.2.2.3 and physical layer blocks as defined defined in 8.2.2.4 as in normal mode
TDD (8.2.2.2) with two differences: firstly, the input data to the physical layer block is equal to all
zeros except for the second to last physical layer block in each burst (see below). Secondly, the
number of physical layer blocks per burst in Table 8-2 is replaced by:

The first bit being sent of the resynchronization header is its LSB. The first bit being sent of the
physical layer block (except the last one) is its MSB. The first bit being sent of the last physical layer
block is its LSB.
The last physical layer block is identical to PhaseSGA as defined in Equation 8-1.
The PCS Scrambler is being run as described in 8.2.2.5.1 for all MLE modes.
For all Speed Grades, scrambled symbols are mapped to PAM2 as in normal mode (4.2.2.6).
