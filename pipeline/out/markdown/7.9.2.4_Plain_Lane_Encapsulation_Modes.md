# 7.9.2.4 Plain Lane Encapsulation Modes

7.9.2.4 Plain Lane Encapsulation Modes
Plain lane encapsulation modes are defined for the DP 8b/10b Link Layer and for the DP 128b/132b
Link Layer. In these modes, the fully coded out of the Main-Link PHY Logical Sublayer is encapsulated
(see Figure 2-8 in [asep_dp_01], where the reference point is output of “Encoder”; or Figure 3-29 in
[asep_dp_01], where the reference point is output of “Pre-Coding”;).
