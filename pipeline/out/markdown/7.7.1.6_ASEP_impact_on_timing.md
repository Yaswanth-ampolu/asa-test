# 7.7.1.6 ASEP impact on timing

7.7.1.6 ASEP impact on timing
The SPI ASEP does not fully maintain SPI bus timing, especially for SPI idle gaps. The minimum SPI idle
gap shall be used to enable compatibility with connected SPI devices. This SPI idle gaps has to be
taken into consideration for payload reservation.
For multiple SPI frames inside one DCP, the last frames position within the DCP is captured and can
be reconstructed.
If precise timing is required for the SPI bus interface, the common ASEP mechanism with PTB
presentation times has to be used and payload data rate adjusted accordingly.
