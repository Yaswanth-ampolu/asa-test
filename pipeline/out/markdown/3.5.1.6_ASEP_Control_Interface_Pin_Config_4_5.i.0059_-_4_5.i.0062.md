# 3.5.1.6 ASEP Control Interface Pin Config (4/5.i.0059 - 4/5.i.0062)

3.5.1.6 ASEP Control Interface Pin Config (4/5.i.0059 - 4/5.i.0062)
The control interface pin configuration is distributed over 4 registers, one for a group of 4 pins each.
Table 3-86 defines the register contents and Table 3-87 shows the mapping between pin groups and
register addresses.
