# 8.6.1.1 Rate Matching

8.6.1.1 Rate Matching
When no data is available from the xMII, the Adapation Layer shall generate data for Rate Matching.
The Rate Matching shall insert control blocks of Block Type 0x1e with all control codes set to “Skip
||R||”0x1C. These rate matching control blocks may be inserted between or during ETH packet
transmission, and will be removed by the receiver.
