# 6.3.1.1 Link Layer Security Algorithms

6.3.1.1 Link Layer Security Algorithms
Link Layer Security shall support AES-GMAC-128 with 128bit LKs by default.
Link Layer Security should support AES-GCM-128 with 128bit LKs.
Link Layer Security may support AES-GMAC-256 with 256bit LKs.
Link Layer Security may support AES-GCM-256 with 256bit LKs.
