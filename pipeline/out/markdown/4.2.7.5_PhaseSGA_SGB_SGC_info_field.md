# 4.2.7.5 PhaseSGA/SGB/SGC info field

4.2.7.5 PhaseSGA/SGB/SGC info field
The info field for PhaseSGA/SGB/SGC inf<511:0> is 60bytes + 4bytes long and defined as follows:
SG
Bit(s) Name | Description
511:480 CRC32 | 32 bit cyclic redundancy check over inf<479:0>
SG
479:43 | Reserved, set to 0
42:19 Info field | Consecutive counter of info fields sent, see also section 4.3.3.1.5
counter
OAMconfigSkip 0: cannot skip OAMconfig phase
1: request by root or far-side node to directly transition into
NormalMode after Startup (usable, if ASA node configuration is
persistently stored and when restarting from Light Sleep)
Has to be confirmed by near-side node by also setting this bit to 1;
otherwise, OAMconfig is not skipped
17:16 PhaseSGstatus Indicates the own status during the startup process:
00: TRAINING
01: PREPARED
10: PROCEED
11: ERROR
15:11 | Reserved, set to 0
10:8 RXtest | Indicates request to go into receiver test mode (see 4.4.1.2):
000: no test requested (startup to normal mode)
110: Noise immunity test
111: BER test
All other values are reserved
7:0 | Reserved, set to 0
Table 4-20: Startup PhaseSGA/SGB/SGC info field
(INFORMATIVE: It is up to the implementer to chose conditions when to signal a PhaseSGstatus
“ERROR” to go back tostartup initialization.)
