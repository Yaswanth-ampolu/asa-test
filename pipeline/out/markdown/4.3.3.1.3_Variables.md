# 4.3.3.1.3 Variables

4.3.3.1.3 Variables
ph1G_self_good: | Boolean variable set by Physical Layer to TRUE, when ready to leave
phase1G
ph1G_all_self_good: Boolean variable, AND concatenation of ph1G_self_good of all Lanes in
Link Aggregation (see section 4.8); equal to ph1G_self_good, when no Link
Aggregation is implemented
phSGA_self_good: | Boolean variable set by Physical Layer to TRUE, when ready to leave
phaseSGA
phSGB_self_good: | Boolean variable set by Physical Layer to TRUE, when ready to leave
phaseSGB
phSGB_all_self_good: Boolean variable, AND concatenation of phSGB_self_good of all Lanes in
Link Aggregation (see section 4.8); equal to phSGB_self_good, when no
Link Aggregation is implemented
phSGC_self_good: | Boolean variable set by Physical Layer to TRUE, when ready to leave
phaseSGC
phSGC_all_self_good: Boolean variable, AND concatenation of phSGC_self_good of all Lanes in
Link Aggregation (see section 4.8); equal to phSGC_self_good, when no
Link Aggregation is implemented
ph1G_lp_stat: | indication of the status received from link partner in phase1G
ph1G_all_lp_stat: | indication of the status received from all link partners in phase1G of Lanes
in Link Aggregation (see section 4.8); only takes a defined value, when all
link partner status are the same
phSGA_lp_stat: | indication of the status received from link partner in phaseSGA
phSGB_lp_stat: | indication of the status received from link partner in phaseSGB
phSGB_all_lp_stat: | indication of the status received from all link partners in phaseSGB of
Lanes in Link Aggregation (see section 4.8); only takes a defined value,
when all link partner status are the same
phSGC_lp_stat: | indication of the status received from link partner in phaseSGC
phSGC_all_lp_stat: | indication of the status received from all link partners in phaseSGC of
Lanes in Link Aggregation (see section 4.8); only takes a defined value,
when all link partner status are the same
ph1G_test_req: | indication of test mode request by link partner (leaf case) or local register
(root case)
phSGA_test_req: | indication of test mode request by link partner (leaf case) or local register
(root case)
ph1G_test_good: | Boolean variable, indication of valid Phase1G info field containing test
result received
