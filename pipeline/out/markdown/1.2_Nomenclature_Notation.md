# 1.2 Nomenclature/Notation

Nomenclature/Notation
<:> … bus signalor signal vector (before serialization) notation
[] … register value
~ … bitwise inversion
! … logical/Boolean inversion
&… logical/Boolean AND
| … logical/Boolean OR
<< … smaller with margin (for additional data)
= … Comparison yielding TRUE or FALSE (when used with “if-then-else” orBoolean operator)
