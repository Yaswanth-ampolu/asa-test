# 5.2.3 Mapping/Multiplexing

5.2.3 Mapping/Multiplexing
The Mapper provides the mechanism for a time-division access of a multitude of DLP_TX (one OAM
and one or more Application Stream Encapsulators and/or Forwarding Fabrics) onto the PLP_TX
(Physical Layer). The Mapper is configurable via ASA registers, which determine the length and
contents of one Mapper Cycle. The Mapper Cycle is a sequence of DLP_TX_IDs that represent the
allocation of container slots to these DLP_TX_IDs.
