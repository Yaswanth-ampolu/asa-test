# 3.4.1 securityPolicy (3.0001)

3.4.1 securityPolicy (3.0001)
Every ASA Device shall have a register for determining the security policy.
This register shall be read-only.
Bit(s) Name | Description | R/W* Access** Privilege***
15:2 Reserved | - | - | - | -
1:0 securityPolicy | Possible Policies | RO L | RID
0b00: No Security
0b01: Authentication only
0b11: Authentication and
Encryption
0b10: Reserved
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
