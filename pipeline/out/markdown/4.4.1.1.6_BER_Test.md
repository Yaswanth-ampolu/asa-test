# 4.4.1.1.6 BER Test

4.4.1.1.6 BER Test
For BER test, the transmitter is operating as in Normal Mode on PCS/PMA at the relative speed
grade, the transmitted pattern is measured in a capturing device using the test fixture 1 shown in
Figure 4-28.
All the d_plp_tx are set to zero and the side stream scrambler is started with seed 0x700000.
The pattern is run for 500 ms, when triggered via startup.
