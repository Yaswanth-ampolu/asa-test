# 4.2.9 CRC32

4.2.9 CRC32
The cyclic redundancy check shall use the polynomial 0xF4ACFB13.
The starting value of the CRC is 0xFFFFFFFF.
The appendix (XOR value) of the CRC is 0xFFFFFFFF.
The input data shall be used byte-wise reflected.
The result data shall be used reflected.
