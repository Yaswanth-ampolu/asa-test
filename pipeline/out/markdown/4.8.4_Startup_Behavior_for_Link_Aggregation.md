# 4.8.4 Startup Behavior for Link Aggregation

4.8.4 Startup Behavior for Link Aggregation
In a Link Aggregation configuration, the Startup procedure synchronizes the half-duplex TDD cycles
between Lanes, see section 4.3.3.1.
In addition, the Physical Layers shall use the flexibility of the timeout period of Startup phases SGA,
SGB and SGC to achieve a staggered start of their transmitted Downstream/Upstream bursts, such
that the relative delay between the first symbol of the burst passing the local MDI of the Lanes is
(measured in line rate symbols):
Lane0 … 0 symbols,
Lane1 … 64 symbols,
Lane2 … 128 symbols,
Lane3 … 192 symbols.
Informative: This stagger avoids the concurrent transmission of resynchronization headers.
