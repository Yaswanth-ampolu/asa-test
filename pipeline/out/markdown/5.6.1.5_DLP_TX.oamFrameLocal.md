# 5.6.1.5 DLP_TX.oamFrameLocal

5.6.1.5 DLP_TX.oamFrameLocal
5.6.1.5.1 Semantics of the primitive
DLP_TX.oamFrameLocal(container, phyLerrStat)
The FoFa uses DLP_TX.oamFrameLocal to signal to the DLL, that it has a container (with an OAM
frame) addressed to the local node. phyLerrStat is equal to errStat in 4.7.1.1.
5.6.1.5.2 When generated
Always, when OAMreturnQueue is not empty and the targetID in the container header is equal to the
local nodeID.
5.6.1.5.3 Effect of receipt
DLL takes data the same way as from PLP_RX (see 4.7.1.1) and feeds it to the Data Link Layer Receive
Process (see 5.3.1)
If nodeID=0 (see 3.3.1), then DLL copies FoFa ReturnPath (see 3.6.1) onto register OAMdmxTX (see
0).
