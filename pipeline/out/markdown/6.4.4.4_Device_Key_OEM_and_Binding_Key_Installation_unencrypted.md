# 6.4.4.4 Device Key OEM and Binding Key Installation (unencrypted)

6.4.4.4 Device Key OEM and Binding Key Installation (unencrypted)
The following process shall only be run to install the DK_1 and BK in a trusted environment for 1 or
more devices:
•
For each device:
o Read out the UUID using KeyEx.read_UUID
o Read out the Key Status using KeyEx.read_status_keys
•
Based on the information read out, acquire the payloads for installing via
KeyEx.install_DK_1_unencrypted and KeyEx.install_BK_encrypted_by_DK_1_only
•
For each device:
o Install DK_1 using KeyEx.install_DK_1_unencrypted
o Install BK using KeyEx.install_BK_encrypted_by_DK_1_only
o Collect returned proofs
o Read out key status
•
Evaluate proofs and key status.
Warning: This process can only be run in a trusted environment since an attacker could recover the
installed keys! You should use the“Device Key OEM and Binding Key Installation (encrypted)”, if
possible.
