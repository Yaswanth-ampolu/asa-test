# 5.5.4.1.1 Generation

5.5.4.1.1 Generation
This message is sent by the root node.
The HeaderType is set to 1, the targetID0 for the container of this OAM frame is set to 0, the
targetID1 is set to that near-side nodeID, behind which further nodes need to be discovered.
CADnext is set to 1, OAMerror is set to 0 (see Table 5-2).
OAMframeID is started with 0, but incremented for every OAM frame with the same set of targetIDs.
There is a single StartEnum command (see 5.5.3.6) in the frame carrying the next (currently still
unused) nodeID for enumeration.
