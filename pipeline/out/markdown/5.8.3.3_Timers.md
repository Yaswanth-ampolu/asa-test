# 5.8.3.3 Timers

5.8.3.3 Timers
timer_LSalarmClock: Timer that is setup to trigger at the wakeup time on PTBclk in PTB tics,
trigger sets timer_LSalarmClock_trigger = TRUE
timer_LSbedtime: | Timer that is setup for the bedtime on PTBclk in PTB tics, trigger sets
timer_LSbedtime_trigger = TRUE
