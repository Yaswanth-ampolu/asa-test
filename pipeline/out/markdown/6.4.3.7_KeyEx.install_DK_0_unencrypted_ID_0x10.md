# 6.4.3.7 KeyEx.install_DK_0_unencrypted (ID: 0x10)

6.4.3.7 KeyEx.install_DK_0_unencrypted (ID: 0x10)
This primitive is used to install the first part of the Device Key persistently.
The ID of this primitive shall be 0x10.
This function shall persistently store the DK_0 and upon success return the status that DK_0 was
written.
The IV and ICV shall only be present, if the Status is OK (0x00).
The device shall check, if the DK_0 was already written and abort with an error (0x20: Already
written before and can only be written once), if this is the case.
The device shall generate the IV based on the construction rules in section 6.4.1.4.
The device shall generate the ICV based on the construction rules in section 6.4.1.6.
