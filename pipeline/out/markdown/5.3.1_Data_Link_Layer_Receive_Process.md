# 5.3.1 Data Link Layer Receive Process

5.3.1 Data Link Layer Receive Process
When PLP_RX is active, the DLL takes received data container by container triggered by 4.7.1.1. For
each container, the following steps are executed:
a) If security is enabled
1. Call primitive 6.3.2.3
2. Wait for LLS to respond
i. In case of 6.3.2.4, execute b)
ii. In case of 6.3.2.5, wait for next container on PLP_RX
b) Execute the cases in 5.3.2 with the values from the current container header
