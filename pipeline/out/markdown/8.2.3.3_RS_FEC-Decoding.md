# 8.2.3.3 RS FEC-Decoding

8.2.3.3 RS FEC-Decoding
The PCS Receive function shall check the integrity of the RS-FEC parity bits defined in 8.2.2.4.
For Speed Grade 3/4/5 based MLE Modes, bit error correction is mandatory. For Speed Grade 1/2
based MLE Modes, bit error correction is optional.
If the correction cannot be done, the RS-FEC frame is invalid.
Statistics shall be kept in the registers described in 3.2.16 and 3.2.13.
