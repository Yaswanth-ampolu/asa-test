# 4.2.4.2 Reed Solomon Encoder (216,214)

4.2.4.2 Reed Solomon Encoder (216,214)
A group of 214 bytes is encoded using a Reed-Solomon encoder operating over the Galois Field
GF(2) where the symbol size is 8 bits (or one byte). The encoder processes k = 214 RS-FEC message
symbols to generate 2t = 2 RS-FEC parity symbols, which are then appended to the message to
produce a codeword of n = k + 2t = 216 RS-FEC symbols.
