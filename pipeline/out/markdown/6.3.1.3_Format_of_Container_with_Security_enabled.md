# 6.3.1.3 Format of Container with Security enabled

6.3.1.3 Format of Container with Security enabled
authentication / integrity check in LLS
payload LLS protection flag | optional encryption in LLS
reserved Counter
Container Header | DLL Payload (secured) | ICV
6:0 (lower byte)
Security Payload
Figure 6-2: Container Format with Security enabled
The Security Entity constructs a Container Payload out of the DLL payload and two additional fields:
Counter and ICV. See also Figure 5-3.
The Container Header HDR contains the bit “KeySwitch” indicating the used key slot(see 5.2.2).
See also section 6.3.4 for handling of these fields during LLS message processing.
