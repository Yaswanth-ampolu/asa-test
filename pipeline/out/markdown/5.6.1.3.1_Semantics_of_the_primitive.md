# 5.6.1.3.1 Semantics of the primitive

5.6.1.3.1 Semantics of the primitive
DLP_TX.oamUnit(oam_payload, targetID, packetID, ndEn, targetIDs)
The OAM uses DLP_TX.oamUnit to provide the payload of a container, the target node identifier and
the packet identifier to the DLL. The size shall be the size, which has been requested. If the OAM
frame uses less bytes than the request size, the OAM shall pad with zeros.
The packetID provided is identical to the lower 5 bits of the OAMframeID (see Table 5-2).
If ndEn=TRUE, the message supplied is a Node-Discover message and targetIDs contains three
additional IDs for an extended header.
