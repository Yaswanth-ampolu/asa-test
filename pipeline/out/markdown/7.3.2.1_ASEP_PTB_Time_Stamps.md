# 7.3.2.1 ASEP PTB Time Stamps

7.3.2.1 ASEP PTB Time Stamps
The second byte contains a switch into ASEP PTB usage:
Byte Bit(s) Name | Description
7:2 | Reserved
1:0 | PTB time stamp | 00: none
01: ingress time stamp
10: presentation time stamp
11: user defined (time stamp size 4 bytes)
Table 7-5: Common ASEP header format–second byte
In case of no time stamping, the maximum byte index m of the common ASEP header format is 1.
