# 4.8.3 PTB Function for Link Aggregation

4.8.3 PTB Function for Link Aggregation
The PTB Clock Leader and PTB Clock Follower shall exchange messages (see section 0), which are
used to update the PTBclk, only via lowest LinkID in use.
All other lanes shall repeat the Follow message (Clock Leader) or Delay Request message (clock
follower).
Informative: The PTB time stamps in these messages can be used to update latency compensation.
