# 6.4.4.1 Startup

6.4.4.1 Startup
•
The Root Device shall have knowledge of the sets (UUID, NodeID) of all branch ASA devices.
Missing relations shall be built by fetching the UUIDs of the respective nodes on startup.
•
A Device shall generate thePower Cycle Nonce (PCN)that should be random and different at
every startup. This shall be finished before answering the first KeyEx.read_current_nonce
request. In case the Power Cycle Nonce is not generated on KeyEx.read_current_nonce
request, the Device shall answer with the error code 0x10 (see section 6.4.1.3) The PCN shall
be identical for all KeyEx.read_current_nonce request in a single power cycle.
•
The Root Node has to guarantee that thePower Cycle Counter (PCC)increments on each
Power Cycle.
