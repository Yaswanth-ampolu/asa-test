# 6.3.1.3.1 Counter

6.3.1.3.1 Counter
Length: 8 bits
Relative Position: Between Container Header and Container Payload
The Counter represents the 8 least significant bits of a 64-bit Link Layer TX AEAD Invocation Counter.
