# 7.9.2.1 Encapsulated Features

7.9.2.1 Encapsulated Features
In Essential Data Mode, this ASEP supports encapsulation of:
- SST Stream Source with a symbol size of 8bit (8b/10b mapping), including
o MSA
o SDP
o VB-ID
o Mvid
o Maud
o Dummy bytes
- DSC-compressed Stream Source
- HDCP-encrypted Stream Source
In Plain Lane Mode, the complete lane-allocated PHY Layer coded stream is encapsulated.
Informative: This is a fail-safe mode with full DP compatibility.
The AUX_CH is separate from the Main Link and always encapsulated the same way.
Informative: As the eDP ASEP encapsulates the basic data fields or Transfer Units of the DP standard,
future updates with backward compatibility within DP like the Automotive Extensions are inherently
supported.
