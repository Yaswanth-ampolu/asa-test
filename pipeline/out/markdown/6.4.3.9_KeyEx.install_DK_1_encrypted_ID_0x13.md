# 6.4.3.9 KeyEx.install_DK_1_encrypted (ID: 0x13)

6.4.3.9 KeyEx.install_DK_1_encrypted (ID: 0x13)
This primitive is used to install the second part of the Device Key persistently.
The ID of this primitive shall be 0x13.
This function shall persistently store DK_1 and the status that DK_1 was written.
This function shall only allow to write DK_1, if it was not written before.
The IV and ICV shall only be present, if the Status is OK (0x00).
The device shall check, if the DK_0 was already written and abort with an error (0x40: Device Key
Part 0 missing), if this is NOT the case.
The device shall check, if the DK_1 was already written and abort with an error (0x20: Already
written before and can only be written once), if this is the case.
The device shall install the DK_1, if DK_1 was not written before.
The device shall generate the IV based on the construction rules in section 6.4.1.4.
The device shall generate the ICV based on the construction rules in section 6.4.1.6.
