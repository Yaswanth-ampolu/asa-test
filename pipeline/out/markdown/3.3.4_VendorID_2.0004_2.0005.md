# 3.3.4 VendorID (2.0004, 2.0005)

3.3.4 VendorID (2.0004, 2.0005)
The vendor identification format is implementer defined.
Register Name | Description | R/W* Access** Privilege***
2.0004 vendorID[15:0] | RO O | RID
vendor identification
2.0005 vendorID[31:16] | RO O | RID
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
