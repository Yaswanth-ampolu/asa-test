# 4.8.2 Sublayer Function

4.8.2 Sublayer Function
The following figure shows the Link Aggregation Sublayer in detail
PLP_TX<dll> | PLP_RX<dll>
Link Aggregation Sublayer
PLP_TX<0:3> | PLP_RX<0:3>
Figure 4-47: Link Aggregation Sublayer
The top side Physical Layer Ports are indexed PLP_TX<dll> and PLP_RX<dll>. The bottom side Physical
Layer Ports are indexed PLP_TX<n> and PLP_RX<n>, where n is 0 through 3 for the up to four Physical
Layers. If only two or three Physical Layers are supported, the higher indices do not exist. The parallel
Physical layers are referred to as Lanes in this chapter.
