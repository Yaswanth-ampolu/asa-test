# 6.3.2.5.1 Semantics of the primitive

6.3.2.5.1 Semantics of the primitive
LinkLayerSec.error_handler(dir, err_code)
Sent back by LLS in case of an error.
dir … direction of Container
0: TX
1: RX
err_code … Error Code for not returning a valid container/payload
AUTH_FAIL … received container authentication failure
DECRYPT_FAIL … received container decryption failure
OAM_FILTER … suppressed OAM message because of missing authentication
