# 4.2.2.3 Resynchronization Header

4.2.2.3 Resynchronization Header
The resynchronization header is used for normal operation and for startup. Its generation is identical
in both modes, except for startup Phase1G, where one field is exchanged, see 4.2.7.1.1.
