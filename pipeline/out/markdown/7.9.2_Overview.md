# 7.9.2 Overview

7.9.2 Overview
The eDP ASEP provides encapsulation formats for the unidirectional Main Link and bi-directional AUX
channel. The Main Link data is encapsulated in the same order as produced by the DP link layer;
either in Essential Data Mode (EDM) or Plain Lane Mode (PLM). The AUX channel is transmitted
bidirectional always completing a transaction. VESA DP defined mechanisms of the Stream/Link
Policy Maker (see [asep_dp_01], section 2.1) are untouched by this specification.
