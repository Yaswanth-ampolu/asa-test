# 5.2.2 Header Generation & Addressing

5.2.2 Header Generation & Addressing
After a new selection of a DLP_TX_ID to transmit, the header is constructed.
In case of an ASEP (see 5.6.1.2), the values to be used for the header fields are take from ASA
registers (see below).
In case of OAM (see 5.6.1.3), the values to be used for the header fields are contained in the
primitive response.
In case of FoFa, the header is not constructed, but supplied in full by the primitive 5.6.1.6.
d_plp_tx Bit(s) Name | Description
<0><0> | HeaderType 0: Basic Container Header is used, no extension
1: Header Extension is used
<0><1> | KeySwitch | Always 0, when no Security Entity is present.
Otherwise, the value provided by the Security Entity
is used.

<0><7> | streamID | Equal to sending DLP_TX_ID
