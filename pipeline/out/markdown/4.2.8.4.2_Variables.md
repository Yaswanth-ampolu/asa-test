# 4.2.8.4.2 Variables

4.2.8.4.2 Variables
PTBint_state: | internal PTB state; can be “unlocked”, “acquisition” or “locked”; only the
internal state “locked” maps to the status bit PTBlocked=1 (see3.3.20)
PTBint_syncedUpdates integer values holding the number of follow updates in sync (see
4.2.8.3.2) of the last ptb_ACQ_window follow updates
