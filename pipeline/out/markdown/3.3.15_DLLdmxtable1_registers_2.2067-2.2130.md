3.3.15DLLdmxtable1 registers (2.2067-2.2130)
The demultiplexer table part01 is distributed over 64 registers, one per DLP_RX_ID. Each register has
the format as shown in Table 3-48.
Bit(s) Name | Description | R/W* Access** Privilege***
15:11 | Reserved
10:6 nodeID | container nodeID for DLP_RX_ID RW O | RID
5:0 streamID container streamID for DLP_RX_ID RW O | RID
* RO=Read only; RW = Read/Write; SC = Self-Clearing; ** L = Local only; O = OAM channel and local;
*** RID = Root nodeID only; A = Authenticated by security
