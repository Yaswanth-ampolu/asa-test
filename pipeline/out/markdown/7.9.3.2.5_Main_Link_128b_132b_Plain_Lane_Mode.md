Table 7-70: ASEP eDP–Main Link Data Packet (128b132b Plain Lane Mode) Header
In 1-Lane payload, a multiple of two 132bit payload symbols are coded. If the fragment of DP data is
not divisible by 2, the last byte of the last 132bit payload is padded with zeros.
Byte | Bit(s) Name | Description
m +4 | 7:0 | Payload_0[131:124] First 132bit payload Lane0
HB
m +5 .. +19 all | Payload_0[123:4]
HB
m +20 | 7:4 | Payload_0[3:0]
HB
m +20 | 3:0 | Payload_1[131:128] Second 132bit payload Lane0
HB
m +21 .. +36 all | Payload_1[127:0]
HB
…
m | 7:0 | Payload_L-1[7:0] Last byte of last 132bit payload Lane0
END
or nibble and 4bit zero-padding
