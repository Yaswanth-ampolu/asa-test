# 6.4.1.7 Generic Fields for KeyEx

6.4.1.7 Generic Fields for KeyEx
The “ID” shall be auint8 field defined as a unique number per KeyEx primitive.
The “Direction” shall be auint8 field defined as follows:
•
0x00: message from Root to Device.
•
0x01: message from Device to Root.
•
0x02-0xff: reserved (don’t use).
Informational: The “Direction” field will be used for secured KeyEx primitives as implicit data.
