# 7.8.2 GPIO Configuration Mode Packet

7.8.2 GPIO Configuration Mode Packet
GPIO configuration mode packet is used to transfer GPIO configuration information from ASA register
in ASA root node to ASA registers in ASA non-root node.
The GPIO ASE in ASA root node issues the write/read command to the GPIO ASE/ASD in the non-root
node. The GPIO ASE/ASD in the non-root node in turn responds with Ack/Nack command to the
Write command and with Read Response command to the Read command.
