# 4.5.8 Narrow-Band Interference (BCI, RF Ingress)

4.5.8 Narrow-Band Interference (BCI, RF Ingress)
Narrow-Band-Interference in the Channel Model a sine wave with single-sided peak amplitude of
40mV for Coax and 25mV for STP from 1-200MHz,
and a sine wave with single-sided peak amplitude of
8mV for Coax and 16mV for STP from 400-5000MHz,
and a linear slope over linear frequency between those values.
