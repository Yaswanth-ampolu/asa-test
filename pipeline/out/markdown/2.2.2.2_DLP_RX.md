# 2.2.2.2 DLP_RX

2.2.2.2 DLP_RX
• DLL→ASD: asynchronous primitive based interface
Features Overview
ASA specifies a half-duplex Physical Layer on Automotive STP and coax cables for asymmetric payload
data rates split between Downstream (high rate) and Upstream (low rate) direction and separated by
an Inter Burst Gap (IBG). The Physical Layer supports 5 fixed-rate Speed Grades in Downstream and 2
fixed-rate Speed Grades in Upstream direction. For all Speed Grade combinations, each direction is
given transmit access to the cable for a defined fraction of a constant time-division duplexing (TDD)
cycle.
A Startup procedure supports automatic startup of link partners into Normal Mode as well as startup
into Test Mode via cable interface. See section 4.
